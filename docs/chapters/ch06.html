💡 1. 為什麼需要這個觀念？（生活化比喻）

  • loc 與 iloc 就像「找座位」的兩種方式：loc 是「按名牌找人」（找『台北』那一列），iloc 是「按座位號碼找人」（找第 0 列）。
  • 條件篩選就像 Excel 的「篩選」按鈕：只留下「新增確診數 ≥ 10000」或「國家 = 台灣」的列。
  • sort_values 與 rank 就像「成績排行榜」：一個是把整張表照分數重新排好，一個是幫每個人標上「第幾名」。
  • apply 就像「影印機的批次處理」：寫好一個規則（例如「數一數有幾科不及格」），一次套用到每一列或每一欄。
  • 相關係數（corr）就像「默契指數」：介於 -1 到 1 之間，越接近 1 代表兩件事「一起漲、一起跌」，接近 0 代表沒什麼關係。
核心概念 生活化直觀比喻 傳統工程師痛苦點 AI 時代你的角色
loc / iloc 按名牌找人 vs. 按座位號找人 兩者混用，取錯資料 說「取出台北、台中兩列的 one、two 欄」
條件篩選 / query Excel 篩選按鈕 多條件 &、` ` 括號寫錯
reindex / drop 重排座位表／請人離席 新增索引出現 NaN 不知原因 說「保留哪些、刪除哪些列或欄」
sort_values / rank 排行榜與名次 同分時名次怎麼算搞不清 指定「由高到低、同分怎麼排」
apply / map 影印機批次處理 axis 方向搞錯 說「對每一位學生」或「對每一科」
describe / corr 健康檢查報告／默契指數 統計名詞看不懂 請 AI 用白話解讀每個數字
資料對齊與 fill_value 兩張名單合併時補空格 結果滿滿 NaN 要求「對不上的補 0」

🔹 核心技巧 1：用 loc / iloc 與條件篩選取出想要的資料

商業意義：從上萬筆資料中，精準取出「某些對象 × 某些指標」，或「符合條件的紀錄」，是回答任何商業問題的第一步。

import pandas as pd                      # 匯入 pandas

df = pd.DataFrame({                      # 模擬疫情資料：一列是一天一個國家
    '國家': ['台灣', '台灣', '台灣', '日本', '日本'],
    '日期': ['2022-05-13', '2022-05-14', '2022-05-15', '2022-02-03', '2022-02-04'],
    '新增確診數': [85000, 128954, 70000, 104345, 98000],
})

print(df.loc[1, ['國家', '新增確診數']])  # loc：取「列名牌 1」的國家與確診數兩欄
print(df.iloc[0:2, 0:2])                 # iloc：取第 0～1 列、第 0～1 欄（依位置，不含結尾）

tw = df[df['國家'] == '台灣']            # 條件篩選：只留下台灣的資料
print(tw[tw['新增確診數'] >= 80000])     # 再篩選：台灣且單日新增 ≥ 8 萬的日子
print(df.query("國家 == '日本' and 新增確診數 > 100000"))  # query：用接近白話的語法寫多重條件

🔹 核心技巧 2：總分、排名與排序——做一份排行榜

商業意義：業務業績排名、門市營收排名、學生成績排名都是同一個套路：先加總、再排名、最後依名次排序。

import pandas as pd                      # 匯入 pandas

scores = pd.DataFrame({'國文': [89, 77, 95, 60],      # 4 位學生 × 3 科成績
                       '英文': [93, 93, 88, 55],
                       '數學': [94, 58, 97, 70]},
                      index=[1, 2, 3, 4])
scores.index.name = '學號'               # 列名牌的標題

scores['總分'] = scores.sum(axis=1)      # axis=1：每位學生橫著加總
scores['排名'] = scores['總分'].rank(method='first', ascending=False)  # 總分由高到低排名；同分時先出現的排前面
print(scores.sort_values(by='排名'))     # 依名次由 1 開始排序，產生排行榜

🔹 核心技巧 3：apply 批次套用自訂規則

商業意義：把「你的業務規則」寫一次，就能套用到每一列或每一欄，例如「數一數每位學生有幾科不及格」或「每一科的最高、最低、中位數」。

import pandas as pd                      # 匯入 pandas

scores = pd.DataFrame({'國文': [89, 77, 55, 60],
                       '英文': [93, 45, 88, 55],
                       '數學': [94, 58, 97, 50]},
                      index=[1, 2, 3, 4])

def count_fail(row):                     # 自訂規則：傳進來的是「一位學生的所有成績」
    return (row < 60).sum()              # 小於 60 的會是 True，加總 True 的數量＝不及格科目數

scores['不及格科數'] = scores.apply(count_fail, axis=1)   # axis=1：對每一列（每位學生）套用
print(scores)

def summary(col):                        # 自訂規則：傳進來的是「一整科的成績」
    return pd.Series([col.min(), col.max(), col.median()], index=['最低分', '最高分', '中位數'])

print(scores[['國文', '英文', '數學']].apply(summary))   # 預設 axis=0：對每一欄（每一科）套用

🔹 核心技巧 4：describe 看全貌、corr 看兩個指標的關係

商業意義：老闆問「廣告費加碼，業績真的會變好嗎？」——用相關係數就能給出有根據的答案。

import pandas as pd                      # 匯入 pandas

data = {'年廣告費投入': [12.5, 15.3, 23.2, 26.4, 33.5, 34.4, 39.4, 45.2, 55.4, 60.9],
        '月均銷售額':   [21.2, 23.9, 32.9, 34.1, 42.5, 43.2, 49.0, 52.8, 59.4, 63.5]}
df = pd.DataFrame(data, index=range(2011, 2021))      # 10 年的廣告費與銷售額（索引是年份）

print(df.describe())                     # 一次看筆數、平均、標準差、最小、四分位數、最大值
r = df['年廣告費投入'].corr(df['月均銷售額'])          # 計算相關係數
print('相關係數：', round(r, 4))         # 結果約 0.9942 → 高度正相關（|r| ≥ 0.7）

💡 相關係數判讀：|r| < 0.4 低度相關；0.4 ≤ |r| < 0.7 中度相關；|r| ≥ 0.7 高度相關。⚠️ 但「相關」不等於「因果」——冰淇淋銷量和溺水人數都在夏天上升，不代表吃冰淇淋會溺水。

⚠️ 驗收小撇步：排名結果請抽查第 1 名與最後 1 名的總分是否正確；篩選結果請檢查「筆數」是否合理（例如台灣的資料不應出現日本）。

🕵️ 真實陷阱案例：本章 Homework3 的 COVID-19 資料中，「解封指數」用 99999 代表「沒有資料」。如果直接算平均，結果會被嚴重灌水！記得請 AI「先檢查是否有用特殊數字代表缺值」。
