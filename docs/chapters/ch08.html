💡 1. 為什麼需要這個觀念？（生活化比喻）

  • 資料整理就像「洗菜備料」：菜市場買回來的菜有泥巴（雜訊列）、有爛葉（異常值）、有重複買的（重複資料）、有缺了一角的（缺值）。洗乾淨、切好，才能下鍋（分析）。業界常說：分析工作有 80% 的時間在備料。
  • 缺值 NaN 就像「問卷沒填的格子」：你可以整份丟掉（dropna）、填上預設值（fillna），或用平均值推估——怎麼處理是商業判斷，不是技術問題。
  • 型態錯誤就像「計算機按到文字鍵」：人口數 '551480' 看起來是數字，其實是文字，加總時會出錯。必須先轉型（astype）。
  • 字串搜尋就像「Ctrl + F」：str.contains('新北市') 就是在整欄裡找出包含「新北市」的列。
核心概念 生活化直觀比喻 傳統工程師痛苦點 AI 時代你的角色
isnull / info 健康檢查報告 不知道髒在哪裡就開始算 先要求 AI「做資料健康檢查」
dropna / fillna 丟掉空白問卷／補上預設答案 一刪就刪掉太多資料 決定「刪除」或「補值」的商業規則
duplicated / drop_duplicates 重複的訂單只留一張 判斷「什麼算重複」 說明「哪些欄位相同才算重複」
replace / map 把 -999、「…」換成正確值 特殊符號藏在角落沒發現 列出所有已知的怪異值
astype 型態轉換 把文字數字變成真數字 一筆髒資料就整欄轉型失敗 要求 AI「找出轉型失敗的那幾筆」
rename / 索引改名 幫欄位換上中文名牌 英文代碼欄位看不懂 提供欄名對照表
str.contains / str.match Ctrl + F 搜尋 正規表示式難寫 用白話描述搜尋規則

🔹 核心技巧 1：缺值的偵測、刪除與填補

商業意義：會員資料缺生日、門市缺某月營收——先知道「缺多少、缺在哪」，再決定刪除或補值，避免平均數被扭曲。

import numpy as np                       # 匯入 NumPy（提供 np.nan 代表缺值）
import pandas as pd                      # 匯入 pandas

df = pd.DataFrame({'門市': ['台北', '台中', '台南', '高雄'],
                   '一月': [120, np.nan, 95, 80],          # 台中一月沒資料
                   '二月': [130, 88, np.nan, np.nan]})      # 台南、高雄二月沒資料

print(df.isnull().sum())                 # 健康檢查：每一欄有幾個缺值（一月 1、二月 2）
print(df.dropna())                       # 只要有缺值就整列刪除 → 只剩台北
print(df.dropna(thresh=2))               # 至少要有 2 個「非缺值」才保留 → 台北、台中、台南留下
print(df.fillna({'一月': 0, '二月': df['二月'].mean()}))  # 一月缺值補 0，二月缺值補該月平均

🔹 核心技巧 2：去除重複、置換異常值

商業意義：系統重複匯入的訂單會讓營收灌水；用 -999 代表「未測量」的感測器數值會讓平均失真。都要在分析前處理掉。

import numpy as np                       # 匯入 NumPy
import pandas as pd                      # 匯入 pandas

orders = pd.DataFrame({'訂單': ['A01', 'A02', 'A02', 'A03'],   # A02 被重複匯入
                       '金額': [500, 300, 300, -999]})          # -999 是系統的「未知金額」代碼

print(orders.duplicated())               # 標記重複列：第 3 筆（索引 2）為 True
orders = orders.drop_duplicates()        # 刪除完全相同的重複列
orders['金額'] = orders['金額'].replace(-999, np.nan)   # 把 -999 換成真正的缺值 NaN
print(orders)
print('平均金額：', orders['金額'].mean())  # 400.0（NaN 不列入計算；若沒置換會被 -999 拉低）

🔹 核心技巧 3：清理人口密度表——改欄名、刪雜訊、轉型

商業意義：這是處理政府開放資料的標準流程。只要一筆「… 」沒處理，整欄就無法轉成數字，後續所有統計都做不了。

import numpy as np                       # 匯入 NumPy
import pandas as pd                      # 匯入 pandas

raw = pd.DataFrame({                     # 模擬原始 CSV 讀進來的樣子（全部都是文字）
    'site_id':      ['區域別', '新北市板橋區', '新北市三重區', '高雄市南沙群島', '資料來源：內政部'],
    'people_total': ['年底人口數', '551480', '387484', '… ', np.nan],
    'area':         ['土地面積', '23.1373', '16.317', '0.5045', np.nan],
})

df = raw.rename(columns={'site_id': '區域', 'people_total': '人口數', 'area': '土地面積'})  # 英文欄名換中文
df = df.drop(0)                          # 刪除第 0 列：那是混進資料裡的第二層標題
df = df.dropna(thresh=2)                 # 非缺值少於 2 個的列（檔尾說明文字）刪掉
df['人口數'] = df['人口數'].replace('… ', 0)   # 「… 」（刪節號＋空白）代表無資料，換成 0
df = df.astype({'人口數': 'int64', '土地面積': 'float64'})  # 文字轉成真正的數字
df['人口密度'] = (df['人口數'] / df['土地面積']).round(0)   # 有了數字，就能計算新指標
print(df)
print(df.dtypes)                         # 確認型態：人口數 int64、土地面積 float64

🔹 核心技巧 4：多重條件搜尋與字串比對

商業意義：找出「人口多但面積小」的高密度區，或「所有新北市的行政區」，是選址、物流、廣告投放常見的問題。

import pandas as pd                      # 匯入 pandas

df = pd.DataFrame({'區域': ['新北市板橋區', '新北市三重區', '新北市永和區', '臺北市大安區', '新竹市香山區'],
                   '人口數': [551480, 387484, 222585, 309969, 77000],
                   '土地面積': [23.14, 16.32, 5.71, 11.36, 54.85]})

dense = df[(df['人口數'] >= 300000) & (df['土地面積'] < 20)]   # 兩個條件都要成立：用 & 連接，每個條件加括號
print(dense)                             # 三重區、大安區

print(df[df['區域'].str.contains('新北市')])      # 欄位文字「包含」新北市
print(df[df['區域'].str.match(r'.*永和區$')])     # 正規表示式：任意開頭、以「永和區」結尾

🤖 4. 指揮 AI 的專屬指令手冊（Prompt 實戰專區）

當你在實務工作遇到此類資料時，直接複製以下 Prompt 讓 AI 替你分析：

📋 AI 指揮範本（通用版）：

「你現在是我的資深 Python 資料分析師。我有一份 [例如：內政部各鄉鎮市區人口密度 CSV，欄位有統計年、區域別、年底人口數、土地面積、人口密度]，我想了解 [例如：人口超過 30 萬且面積小於 20 平方公里的行政區]。

請你：

  1. 先用 pandas 做一次「資料健康檢查」：列出每欄的型態、缺值數量、重複列數量，以及無法轉成數字的值有哪些。
  2. 依照我的規則清理：[例如：檔尾說明文字刪除；「…」視為 0；缺值補 0；重複列刪除]，並詳細解釋每一步的處理邏輯。
  3. 產出繁體中文說明的完整程式碼，並標註潛在的資料異常陷阱，以及清理前後的筆數變化。」

🎯 情境延伸範本（依需求替換）：

你想問的商業問題 直接對 AI 說
不知道資料哪裡髒 「請用 info()、isnull().sum()、duplicated().sum() 檢查這份資料，並用白話告訴我有哪些問題。」
轉型一直失敗 「人口數欄轉成整數時失敗，請找出所有無法轉換的值、它們在第幾列，並建議處理方式。」
缺值要怎麼補 「銷售資料有缺值，請比較『刪除』、『補 0』、『補該門市平均』三種做法，對總營收與平均的影響。」
統一文字格式 「客戶名單的電話有的有 -、有的有空白、有的開頭少 0，請統一成 09xxxxxxxx 格式，並列出無法修正的資料。」
找出特定文字 「請篩選出地址包含『新北市』且以『區』結尾的資料，並抽出 email 的網域名稱（如 gmail.com）。」

⚠️ 驗收小撇步：每做一步清理，都請 AI 印出「清理前筆數 → 清理後筆數」。如果一次少了一大半，很可能是規則太嚴格（例如 dropna() 把只缺一格的列也刪了）。

🕵️ 真實陷阱案例：本章 example1 中，人口數欄位轉整數一直失敗，追查後發現兇手是一個 「… 」（刪節號＋一個空白）。肉眼幾乎看不出來，卻讓整欄無法計算。這正是要請 AI「列出所有無法轉換的值」的原因。
