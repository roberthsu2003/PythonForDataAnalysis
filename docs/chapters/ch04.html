💡 1. 為什麼需要這個觀念？（生活化比喻）

  • 一般的 Python 清單（list）就像「購物袋」：什麼都能丟進去（數字、文字混在一起），但要算總價時，你得一件一件拿出來看標籤、再加總。
  • NumPy 陣列（array）就像「蛋盒」：每一格大小一樣、只放同一種東西。因為規格統一，你可以「整盒一起秤重」、「整盒一起漲價 10%」，一個動作就搞定。
  • 在 Excel 裡，你要把 A 欄加 B 欄，得寫好公式再往下拉到第 50 列；在 NumPy 裡，你只要說「A 欄 + B 欄」，50 列（甚至 100 萬列）瞬間同時算完。這就叫做 向量化運算。
  • Notebook 裡實測：同樣把 100 萬個數字乘以 2，NumPy 比一般清單快上數十倍。資料越大，差距越明顯。
核心概念 生活化直觀比喻 傳統工程師痛苦點 AI 時代你的角色
陣列（ndarray） 蛋盒：每格同規格、只放同類東西 要記 np.array()、dtype 等語法 告訴 AI「把這些數字轉成 NumPy 陣列」
向量化運算 Excel 整欄一次套公式，不用往下拉 習慣寫 for 迴圈，又慢又容易寫錯 要求 AI「不要用迴圈，整批計算」
形狀（shape）與重排（reshape） 12 顆蛋可以排成 2×6 或 3×4 的盒子 形狀對不上就報錯，看不懂錯誤訊息 說清楚「幾列、幾欄、每列代表什麼」
軸（axis） 「橫著加」算每人總分 vs.「直著加」算每科總分 axis=0 / axis=1 常常搞反 用白話說「每位學生」或「每個科目」，並驗收結果筆數
布林篩選 / np.where 用螢光筆把「不及格」的格子標出來 條件寫錯，篩出空資料也沒發現 下達清楚條件，並抽查幾筆確認
累計（cumsum） 存錢筒：每天存的錢一路累加 自己寫累加邏輯容易少算一天 要求 AI 畫出累計曲線，判讀趨勢

💻 3. 核心精華操作（複製貼上即可驗證）

學生不需要自己寫，但只要讀懂關鍵邏輯即可。

🔹 核心技巧 1：整批運算（不用迴圈）

商業意義：兩份名單（例如上半年與下半年業績、國文與英文成績）要逐筆相加時，一行就搞定，資料量再大也不怕。

import numpy as np                       # 匯入 NumPy 套件，並取個簡短的暱稱 np

chinese = [80, 60, 92, 75]               # 一般的 Python 清單：4 位學生的國文成績
english = [90, 75, 68, 88]               # 一般的 Python 清單：同樣 4 位學生的英文成績

print(chinese + english)                 # ⚠️ 清單相加只會「接在一起」：[80, 60, 92, 75, 90, 75, 68, 88]

nd_chinese = np.array(chinese)           # 把清單轉成 NumPy 陣列（裝進蛋盒）
nd_english = np.array(english)           # 英文成績也轉成陣列

total = nd_chinese + nd_english          # ✅ 陣列相加是「對應位置逐一相加」
print(total)                             # 結果：[170 135 160 163]，每位學生的兩科總分
print(total * 1.1)                       # 整批調整：每個人的總分都乘以 1.1（例如加權）

🔹 核心技巧 2：用 axis 做「每人」與「每科」統計

商業意義：同一張表可以回答兩種問題——「哪個人表現最好？」（橫著算）與「哪個項目最弱？」（直著算）。換成「分店 × 月份」的營收表也一樣適用。

import numpy as np                       # 匯入 NumPy

# 建立 3 位學生 × 3 科的成績表（列 = 學生，欄 = 科目：國文、英文、數學）
scores = np.array([[80, 90, 70],         # 小明
                   [60, 75, 95],         # 小華
                   [88, 62, 79]])        # 小美

print(scores.shape)                      # 查看形狀：(3, 3) 代表 3 列 3 欄
print(scores.sum(axis=1))                # axis=1 橫著加 → 每位學生總分：[240 230 229]
print(scores.mean(axis=0))               # axis=0 直著平均 → 每一科的平均：約 [76. 75.67 81.33]
print(scores.max())                      # 不指定 axis → 整張表的最高分：95
print(np.median(scores))                 # 整張表的中位數：79.0（比平均更不受極端值影響）

🔹 核心技巧 3：條件篩選與標記（布林索引 + np.where）

商業意義：快速找出「不及格的學生」、「低於目標的門市」，並自動貼上標籤，等同於 Excel 的「篩選」加上 IF() 公式。

import numpy as np                       # 匯入 NumPy

sales = np.array([5200, 3100, 7800, 2900, 6100])   # 5 家門市本月營收（單位：千元）

is_low = sales < 4000                    # 逐一判斷是否低於 4000，得到 True / False 的「螢光筆標記」
print(is_low)                            # 結果：[False  True False  True False]
print(sales[is_low])                     # 只取出被標記的門市營收：[3100 2900]

# np.where(條件, 符合時的值, 不符合時的值) ── 就像 Excel 的 IF()
label = np.where(sales < 4000, '需輔導', '達標')
print(label)                             # 結果：['達標' '需輔導' '達標' '需輔導' '達標']

🔹 核心技巧 4：累計營收趨勢（cumsum）＋ 畫成折線圖

商業意義：老闆最常問「這個月到今天為止累積賺了多少？」。cumsum() 一行算出每天的累計值，畫成圖就能看出業績是穩定成長還是突然停滯。

import numpy as np                       # 匯入 NumPy
import matplotlib.pyplot as plt          # 匯入繪圖套件

week_income = np.array([456, 896, 278, 832, 940, 1265, 689])  # 一週 7 天的每日收入

cum_income = week_income.cumsum()        # 累計加總：每天 = 前面所有天數的總和
print(cum_income)                        # 結果：[ 456 1352 1630 2462 3402 4667 5356]

plt.plot(range(1, 8), cum_income, 'r-o') # 以第 1～7 天為 X 軸、累計收入為 Y 軸，畫紅色折線
plt.title('Weekly Cumulative Income')    # 圖表標題（用英文可避免中文字型顯示成方塊）
plt.xlabel('Day')                        # X 軸名稱
plt.ylabel('Income')                     # Y 軸名稱
plt.show()                               # 顯示圖表

🤖 4. 指揮 AI 的專屬指令手冊（Prompt 實戰專區）

當你在實務工作遇到此類資料時，直接複製以下 Prompt 讓 AI 替你分析：

📋 AI 指揮範本（通用版）：

「你現在是我的資深 Python 資料分析師。我有一份 [例如：5 家分店 × 30 天的每日營收數字]，我想了解 [例如：每家分店的總營收、平均日營收，以及哪幾天營收低於 3000 元]。

請你：

  1. 使用 NumPy 陣列 進行處理，不要用 for 迴圈逐筆計算。
  2. 詳細解釋每一步的處理邏輯與計算公式，特別說明使用的是 axis=0 還是 axis=1，以及它代表「每家分店」還是「每一天」。
  3. 產出繁體中文說明的完整程式碼，並標註潛在的資料異常陷阱（例如缺值、數字被存成文字、輸入時少了逗號）。」

🎯 情境延伸範本（依需求替換）：

你想問的商業問題 直接對 AI 說
每位員工的季度總業績 「這是 10 位員工 × 4 季的業績表，每一列是一位員工，請用 NumPy 算出每人全年總業績並由高到低排序。」
業績是否穩定成長 「請把這 30 天的營收用 cumsum() 算出累計值，畫成折線圖，並用白話說明趨勢有無停滯。」
自動標記警示名單 「請用 np.where 把平均分數低於 60 的學生標記為『需補救』，其他標記為『正常』。」
資料想換個排列方式 「我有 12 個月的數字排成一長串，請 reshape 成 4 季 × 3 個月的表格，並解釋每列每欄代表什麼。」

⚠️ 驗收小撇步：AI 給你結果後，請自己抽查 1～2 筆（例如手算第一位學生的總分），並確認「結果的筆數」符合預期——要算「每位員工」，結果的數字個數就應該等於員工人數。

🕵️ 真實陷阱案例：本章的課後練習資料中有一筆寫成 8409.8406——原本應是 8409, 8406 兩個月份，卻因為少打一個逗號，變成一個帶小數的數字，17 個月的資料只剩 16 筆！這正是你要請 AI「標註資料異常」的原因。
