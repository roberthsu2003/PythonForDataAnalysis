💡 1. 為什麼需要這個觀念？（生活化比喻）

  • groupby 就像「班級分組報告」：老師把全校學生依班級分組（Split），每組各自算平均分數（Apply），最後把各班結果整理成一張表（Combine）。
  • 在 Excel 裡，這相當於「排序 → 小計」或「樞紐分析表」；在 pandas 裡，只要一行 df.groupby('班級')['分數'].mean()。
  • agg 就像「一次點多道菜」：同一組資料，一次算出平均、最大、最小、筆數，不用分開寫好幾次。
  • pd.cut 就像「把年齡分成年齡層」：0～17 歲、18～34 歲、35～54 歲……把連續的數字切成幾個區間，再分組比較。
核心概念 生活化直觀比喻 傳統工程師痛苦點 AI 時代你的角色
groupby 依班級分組 用迴圈逐組計算，又慢又長 說「依 ___ 分組」
sum / mean / count 每組算總和、平均、人數 count 不計缺值，數字對不上 說「計算 ___ 的 ___」
多欄分組 依「年級 + 班級」分組 多層索引看不懂 說「依日期和是否吸菸兩個欄位分組」
agg 一次點多道菜 自訂欄名的寫法複雜 列出要的統計量與中文欄名
pd.cut / qcut 把年齡切成年齡層 區間邊界包含與否搞不清 說「切成 4 個等寬區間」或「依人數四等分」
pivot_table Excel 樞紐分析表 參數多、margins 小計設定 描述「列、欄、值、計算方式」
分組後新增比率 各區故障率 = 故障 ÷ 總數 先除後加、還是先加後除算錯 要求「先加總，再計算比率」

🔹 核心技巧 1：基本分組統計（Split-Apply-Combine）

商業意義：「各區有多少車位？」、「各門市營收多少？」、「各部門平均薪資？」——所有「各○○的△△」問題，都是一行 groupby。

import pandas as pd                      # 匯入 pandas

bikes = pd.DataFrame({'站名': ['大鵬華城', '裕隆公園', '汐止火車站', '汐止區公所', '板橋車站'],
                      '區域': ['新店區', '新店區', '汐止區', '汐止區', '板橋區'],
                      '數量': [38, 40, 56, 46, 80],
                      '可借': [13, 20, 30, 20, 50],
                      '可還': [25, 18, 22, 24, 28]})

bikes['故障'] = bikes['數量'] - (bikes['可借'] + bikes['可還'])   # 故障數 = 總車位 − 可借 − 可還

result = bikes.groupby('區域')[['數量', '故障']].sum()   # 依「區域」分組，加總數量與故障
result['故障率'] = result['故障'] / result['數量']        # 先加總、再相除，得到各區故障率
print(result.sort_values('故障率', ascending=False))     # 依故障率由高到低排序，找出最需維修的區域

🔹 核心技巧 2：多欄分組＋ agg 一次算多種統計

商業意義：同時比較「星期幾 × 是否吸菸」的顧客，平均給多少小費、最多給多少、有幾筆——用 agg 一次產出完整的比較表。

import pandas as pd                      # 匯入 pandas

url = ('https://raw.githubusercontent.com/roberthsu2003/PythonForDataAnalysis/master/'
       '%E7%BE%A4%E7%B5%84%E8%B3%87%E6%96%99%E5%92%8C%E7%BE%A4%E7%B5%84%E9%81%8B%E7%AE%97/tips.csv')
tips = pd.read_csv(url)                  # 直接從 GitHub 讀取本章的 tips 小費資料集（244 筆餐廳帳單）
tips.columns = ['帳單金額', '小費', '吸菸者', '星期', '時段', '人數']   # 欄名改成中文
tips['小費比例'] = tips['小費'] / tips['帳單金額']                     # 新增指標：小費佔帳單的比例

grouped = tips.groupby(['星期', '吸菸者'])          # 兩個欄位一起分組：星期 × 是否吸菸
summary = grouped['小費比例'].agg([('筆數', 'count'),   # agg 傳入 (中文欄名, 統計方法) 的清單
                                  ('平均', 'mean'),
                                  ('最大值', 'max')])
print(summary.round(3))                  # 四捨五入到小數 3 位

🔹 核心技巧 3：pd.cut 把數字切成區間再分組

商業意義：把客戶依消費金額分成「小額、中額、大額」，或把人口依規模分級，再比較每一級的特徵——這就是「客群分級」的基礎。

import pandas as pd                      # 匯入 pandas

orders = pd.DataFrame({'訂單金額': [120, 850, 2300, 450, 5200, 90, 1500, 3100],
                       '是否回購': [0, 1, 1, 0, 1, 0, 1, 1]})   # 1 = 有回購，0 = 沒回購

orders['金額級距'] = pd.cut(orders['訂單金額'],
                          bins=[0, 500, 2000, 10000],           # 自訂切點：0～500、500～2000、2000～10000
                          labels=['小額', '中額', '大額'])      # 每個區間的名稱
print(orders.groupby('金額級距', observed=True)['是否回購'].agg(['count', 'mean']))  # 各級距的筆數與回購率

🔹 核心技巧 4：pivot_table 樞紐分析表（含小計）

商業意義：這就是 Excel 樞紐分析表的程式版。列放「時段」、欄放「是否吸菸」、值放「平均小費比例」，再加上「全部」小計，一張表看完所有交叉比較。

import pandas as pd                      # 匯入 pandas

url = ('https://raw.githubusercontent.com/roberthsu2003/PythonForDataAnalysis/master/'
       '%E7%BE%A4%E7%B5%84%E8%B3%87%E6%96%99%E5%92%8C%E7%BE%A4%E7%B5%84%E9%81%8B%E7%AE%97/tips.csv')
tips = pd.read_csv(url)                  # 讀取 tips 資料集
tips['tip_pct'] = tips['tip'] / tips['total_bill']   # 小費比例

table = pd.pivot_table(tips,
                       index=['time', 'day'],        # 列：時段（午餐/晚餐）× 星期
                       columns='smoker',             # 欄：是否吸菸
                       values='tip_pct',             # 值：小費比例
                       aggfunc='mean',               # 計算方式：平均
                       margins=True,                 # 加上「All」小計列與小計欄
                       observed=True)                # 只顯示實際出現過的組合
print(table.round(3))

各縣市彙總 「區域別欄位是『新北市板橋區』這種格式，請取前三個字當縣市，再依縣市加總人口與面積，找出人口最多與最少的縣市。」

⚠️ 驗收小撇步：分組後請 AI 把各組的「筆數」或「總和」加起來，確認等於原始資料的總筆數或總和——對得上，才代表沒有資料在分組時遺失。

🕵️ 真實陷阱案例：本章 Homework1 用「區域別的前三個字」當縣市，例如「新北市板橋區」→「新北市」。但遇到「東沙群島」、「南沙群島」這種名稱就會切錯，而且它們的人口數是「…」，必須先清理再分組，否則加總會出錯。
