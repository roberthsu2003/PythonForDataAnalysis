📐 第三章・圖表詞彙與軸線原理

常用圖表名稱與座標軸配置指南

掌握長條圖、直方圖、散佈圖的中英文名稱與 X/Y 軸職責分配，避開坐標軸放置地雷，精準指揮 AI 產出商業圖表！

📊 垂直長條圖 Column Chart
比較類
X 軸： 少數類別 (≤ 6 個，如部門、產品)
Y 軸： 連續數值指標（⚠️ 必須從 0 起算）

比較少數類別的業績、花費或數量高低差距。類別少時直立挺拔，一目瞭然。

plt.bar(df['部門'], df['金額'])
📊 水平長條圖 Horizontal Bar Chart (barh)
比較類・首選
X 軸： 連續數值指標（從 0 向右展開）
Y 軸： 類別名稱（文字由左至右水平閱讀）

職場排名最強圖表！ 項目多（≥ 7 個）或名稱很長時，依數值由大到小排序展開。

plt.barh(df['項目'], df['數值'])
📊 分組長條圖 Grouped Bar Chart
比較類
X 軸： 主要分組類別（如各部門）
Y 軸： 數值指標 ＋ 圖例（今年 vs 去年）

在同一類別內同時比對「目標 vs 實際」或「今年 vs 去年」的雙指標落差。

sns.barplot(x='部門', y='金額', hue='年度')
📊 百分比長條圖 100% Stacked Bar Chart
組成類・首選
軸線： 一軸為分類，另一軸為 0% ~ 100% 百分比
特徵： 色塊總長固定為 100%，易比對長度

看內部結構占比的首選！ 比圓餅圖更容易讓眼睛精確比較比例差距。

df_pct.plot(kind='bar', stacked=True)
🥧 甜甜圈 / 圓餅圖 Donut / Pie Chart
組成類・有條件
軸線： 無 X/Y 軸（以圓心角與切片弧長代表比例）
禁忌： 類別必須 ≤ 4 個，嚴禁 3D 傾斜

僅適用於類別極少且想強調某一個「過半壓倒性主導份額」的情境。

plt.pie(df['金額'], labels=df['類別'])
📶 直方圖 Histogram
分布類・看形狀
X 軸： 連續數值切成的等寬區間 (Bins)
Y 軸： 落入該區間的次數／筆數 (Count)

看成百上千筆數字大多落在哪個區間。柱子與柱子緊密相連，代表連續數值。

plt.hist(df['薪資'], bins=10)
📦 箱形圖 / 盒鬚圖 Box Plot
分布類・抓異常
數值軸： 連續度量數值（中位數、四分位 Q1/Q3）
分組軸： 各部門或品類（可選，進行並列比較）

秒抓離群極端值！ 檢視平均數是否被極端值欺騙的最佳利器。

sns.boxplot(x='部門', y='通勤時間')
🔘 散佈圖 Scatter Plot
關係類・雙數值
X 軸： 連續數值變數 A（如：預估工時）
Y 軸： 連續數值變數 B（如：實際工時）

檢驗兩指標是否同步升降（正負相關）。切勿用線條將點連起來！

plt.scatter(df['預估'], df['實際'])
🌡️ 相關係數熱力圖 Correlation Heatmap
關係類・多變數
X/Y 軸： 各個連續數值欄位名稱的矩陣交叉
顏色： 相關係數 r (-1 ~ +1)，深淺反映強弱

多個數值欄位兩兩關係的全景掃描工具。提醒：相關不代表因果！

sns.heatmap(df.corr(), annot=True)
📈 折線圖 Line Chart
趨勢類・時間序
X 軸： 時間型態（日期、月份，嚴格由早到晚）
Y 軸： 連續數值指標（金額、流量）

連續時間點（> 5 個）看成長、衰退與週期性。非時間類別嚴禁連線。

plt.plot(df['日期'], df['營收'])
