情境與資料

主管交給你一份 Excel，希望你完成下面的任務，並能說明結果如何算出來。 本例為固定的教學模擬資料，姓名、單號與金額不對應真實公司。

  • 資料：6 筆；欄位：領用單號、部門、品項、數量。

計算規則：單號是文字；數量是件數。不同品項先分開看，不把件數解讀為費用。

跟著做

  1. 列出工作表名稱、欄位與前 3 筆資料。
  2. 說明一列代表一筆領用明細，計算資料筆數。
  3. 只列出行政部的領用紀錄。

先在 Excel 人工找出兩筆資料核對，再把下列需求交給 AI。一次完成一個步驟，確認結果後再繼續。

參考程式

本機需安裝 openpyxl numpy matplotlib。在 Colab 先執行 !pip -q install openpyxl numpy matplotlib，再上傳本例 Excel。 圖表使用英文標題避免環境缺少中文字型，圖中的代碼可回查來源表。

from pathlib import Path
import csv
from openpyxl import load_workbook

# 本機：把 Notebook 與 Excel 放在同一資料夾。Colab：先上傳本例 Excel。
SOURCE = Path('01_行政_文具領用.xlsx')
if not SOURCE.exists():
    try:
        from google.colab import files
    except ImportError:
        raise FileNotFoundError(f'請將 {SOURCE.name} 放到目前工作目錄：{Path.cwd()}')
    files.upload()
if not SOURCE.exists():
    raise FileNotFoundError(f'尚未找到 {SOURCE.name}，請確認上傳檔名')
OUT = Path('output') / '01_行政_文具領用'
OUT.mkdir(parents=True, exist_ok=True)

def read_rows(sheet):
    data = sheet.iter_rows(values_only=True)
    headers = next(data)
    return [dict(zip(headers, row)) for row in data if any(v is not None for v in row)]

def save_csv(name, records):
    if not records:
        print('沒有符合條件的資料，未輸出 CSV')
        return
    with (OUT / name).open('w', newline='', encoding='utf-8-sig') as f:
        writer = csv.DictWriter(f, fieldnames=list(records[0]))
        writer.writeheader()
        writer.writerows(records)

# 來源檔只有原始值，沒有需要重算的 Excel 公式。
wb = load_workbook(SOURCE, read_only=True, data_only=True)
print('工作表：', wb.sheetnames)
rows = read_rows(wb['資料'])
print('第一筆：', rows[0])

print('欄位：', list(rows[0]))
print('前 3 筆：', rows[:3])
print('筆數：', len(rows))
selected = [r for r in rows if r['部門'] == '行政']
print('行政部：', selected)
assert len(rows) == 6 and len(selected) == 2

wb.close()
