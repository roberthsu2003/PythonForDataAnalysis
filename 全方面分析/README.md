## 💡 1. 為什麼需要這個觀念？（生活化比喻）

- **完整的資料分析就像「做一道大菜」**：先決定菜色（提出問題）→ 買菜（載入資料）→ 檢查食材（探索）→ 洗菜去爛葉（清理）→ 切菜醃肉（轉換、建立新欄位）→ 烹調（分析）→ 擺盤（視覺化）→ 上菜並說明（結論與建議）。少了任何一步，菜都不會好吃。
- **AI 就像「手腳很快的助理廚師」**：它可以在幾秒內完成每一步，但**它不知道你的商業脈絡**。例如「臺北車站人特別多」是事實，不是錯誤；如果助理把它當成「異常」修掉，整道菜就走味了。
- **你的角色是「主廚」**：決定每一步要做什麼、檢查每一步的成果，並對最後的結論負責。

| **分析階段** | **生活化直觀比喻** | **常見的坑** | **AI 時代你的角色** |
| -------- | ----------- | ------------ | ------------- |
| 提出問題 | 決定今天要做什麼菜 | 沒有問題就開始亂算 | 先寫下 3～4 個要回答的商業問題 |
| 載入資料 | 買菜 | 編碼錯誤、檔案路徑錯 | 請 AI 自動嘗試 UTF-8 / Big5 |
| 探索資料 | 檢查食材 | 沒看分布就直接分析 | 要求 AI 報告型態、缺值、描述統計、分布圖 |
| 清理資料 | 洗菜去爛葉 | **把真實的大數字當成異常值刪掉** | 判斷「極端值是錯誤，還是真實現象」 |
| 轉換資料 | 切菜醃肉 | 日期沒轉型、代碼沒對應名稱 | 指定要新增的欄位與公式 |
| 分析 | 烹調 | 平均值被少數大站拉高 | 同時看平均數與中位數 |
| 視覺化 | 擺盤 | 中文變方塊、圖表沒有標題 | 指定圖表類型與標題 |
| 結論與建議 | 上菜並說明 | 把「相關」說成「因果」 | 用白話寫出發現與下一步 |

### 🔹 核心技巧 1：載入與探索——先做「資料健康檢查」

**商業意義**：在下任何結論之前，先確認資料「有多少筆、涵蓋哪段時間、有沒有缺值、數字分布長什麼樣子」，避免建立在錯誤資料上的決策。

```python
import pandas as pd                      # 匯入 pandas

url = ('https://raw.githubusercontent.com/roberthsu2003/PythonForDataAnalysis/master/'
       '%E5%85%A8%E6%96%B9%E9%9D%A2%E5%88%86%E6%9E%90/'
       '%E6%AF%8F%E6%97%A5%E5%90%84%E7%AB%99%E9%80%B2%E5%87%BA%E7%AB%99%E4%BA%BA%E6%95%B82023.csv')
df = pd.read_csv(url)                    # 直接從 GitHub 讀取 2023 年每日各站進出站人數

print(df.shape)                          # (86609, 4)：8.6 萬筆、4 個欄位
print(df.dtypes)                         # 注意：日期 trnOpDate 與車站代碼 staCode 都被讀成整數
print(df.isnull().sum())                 # 每欄缺值數量（本資料為 0）
print(df['staCode'].nunique(), '個車站')  # 241 個車站
print(df[['gateInComingCnt', 'gateOutGoingCnt']].describe())  # 平均約 2,600 人，但最大值高達 9 萬多 → 分布非常不平均
```

### 🔹 核心技巧 2：轉換——建立日期、總運量、淨流量、星期欄位

**商業意義**：原始資料只有「進站、出站」，分析需要的指標（總運量、淨流量）與時間維度（星期、月份）要自己建立，這一步決定了後面能回答哪些問題。

```python
# 接續核心技巧 1 的 df
df['日期'] = pd.to_datetime(df['trnOpDate'], format='%Y%m%d')   # 整數 20230101 → 真正的日期（指定格式最安全）
df['總運量'] = df['gateInComingCnt'] + df['gateOutGoingCnt']      # 總運量 = 進站 + 出站
df['淨流量'] = df['gateInComingCnt'] - df['gateOutGoingCnt']      # 淨流量 = 進站 − 出站（正數＝出發多於抵達）
weekday_map = {0: '星期一', 1: '星期二', 2: '星期三', 3: '星期四', 4: '星期五', 5: '星期六', 6: '星期日'}
df['星期'] = df['日期'].dt.dayofweek.map(weekday_map)              # 0～6 對應成中文星期
df['月份'] = df['日期'].dt.month                                   # 取出月份

by_weekday = df.groupby('星期')['總運量'].mean().reindex(list(weekday_map.values()))  # 各星期平均，依星期一～日排序
print(by_weekday.round(0))               # 可以看出星期五最高
```

### 🔹 核心技巧 3：趨勢分析——每日全網運量與 7 日移動平均

**商業意義**：每天的運量受假日、天氣影響起伏很大；7 日移動平均剛好涵蓋一整週，能濾掉「週間 vs. 週末」的週期，看出全年真正的趨勢。

```python
# 接續核心技巧 2 的 df
import matplotlib.pyplot as plt          # 匯入繪圖套件

daily_total = df.groupby('日期')['總運量'].sum()          # 每天全台鐵的總運量（所有車站加總）
fig, ax = plt.subplots(figsize=(12, 4))
daily_total.plot(ax=ax, alpha=0.3, label='Daily total')               # 每日總運量（淡色）
daily_total.rolling(7).mean().plot(ax=ax, label='7-day moving average')  # 7 日移動平均（趨勢線）
ax.set_title('2023 TRA daily ridership')
ax.legend()
plt.show()

print(daily_total.resample('ME').mean().round(0))         # 每月的平均日運量，比較淡旺季
```

### 🔹 核心技巧 4：高運量車站——合併站名，並比較「清理前 vs. 清理後」

**商業意義**：「代碼 1000」對主管沒有意義，「臺北」才有。合併站名之後，再檢查清理極端值的方法是否把真實的大站「誤傷」。

```python
# 接續核心技巧 2 的 df
import numpy as np                       # 匯入 NumPy

station_url = ('https://raw.githubusercontent.com/roberthsu2003/PythonForDataAnalysis/master/'
               '%E6%95%B8%E6%93%9A%E6%95%B4%E7%90%86_%E9%80%A3%E6%8E%A5_%E5%90%88%E4%BD%B5_%E9%87%8D%E5%A1%91/'
               '%E5%8F%B0%E9%90%B5%E8%BB%8A%E7%AB%99%E8%B3%87%E8%A8%8A.csv')
stations = pd.read_csv(station_url, usecols=['stationCode', 'stationName'])   # 台鐵車站代碼與站名對照表

top_raw = df.groupby('staCode')['總運量'].mean().nlargest(5).reset_index()  # 清理前：平均總運量前 5 名
top_raw = top_raw.merge(stations, left_on='staCode', right_on='stationCode', how='left')  # 補上站名
print(top_raw[['staCode', 'stationName', '總運量']].round(0))     # 臺北約 11.8 萬，遠高於其他站

capped = df.copy()                       # 對照組：模擬「用全體第 99 百分位數截斷極端值」的錯誤清理方式
for col in ['gateInComingCnt', 'gateOutGoingCnt']:
    capped[col] = np.clip(capped[col], None, capped[col].quantile(0.99))    # 超過 99% 分位數的值一律壓到上限
capped['總運量'] = capped['gateInComingCnt'] + capped['gateOutGoingCnt']
print(capped.groupby('staCode')['總運量'].mean().nlargest(5).round(0))   # 臺北被壓到約 5.5 萬，臺中（3300）掉出前 5
```
