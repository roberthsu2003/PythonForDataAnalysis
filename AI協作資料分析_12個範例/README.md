### 🌐 關鍵轉折：為什麼要引入「互動介面」？（Streamlit 應用說明）

在前 5 個範例中，我們已經學會如何透過 AI 整理數據並匯出標準的 Excel 靜態報表。但在現代商業情境中，主管、業務或客戶往往需要**「自己動手點選」**：
- 想看特定門市或縣市的數字？不需要重新跑一次程式，拉動**下拉選單**就能切換。
- 想看特定日期區間或年齡層？不需要手動改條件，拖動**時間滑桿**圖表就即時重繪。

#### 為什麼選擇 Streamlit？
評估現代所有 Python 介面工具後（詳見 [最適合搭配的介面工具比較表](../最適合搭配的介面工具比較表.md)），**Streamlit** 是零程式碼學員與 AI 協作的最強利器：
1. **零前端技術負擔**：完全不需要學習 HTML、CSS 或 JavaScript，所有介面元件純靠 Python 定義。
2. **AI 協作產出極佳**：AI 非常擅長撰寫 Streamlit 程式碼，結構乾淨且幾乎零除錯成本。
3. **豐富的即時互動元件**：
   - 下拉選單 (`st.selectbox`)、多選標籤 (`st.multiselect`)
   - 數值/日期滑桿 (`st.slider`, `st.date_input`)
   - 互動式數據表格 (`st.dataframe`) 與即時圖表渲染 (`st.pyplot`)

#### 零程式碼學員如何指揮 AI 建立介面？
學員依然不需要自己寫前端代碼！在完成 Notebook 邏輯後，只需給本機 AI 助教一段自然語言指示：
> *「請讀取 Notebook 的計算邏輯，幫我建立一個 Streamlit 應用 `app.py`：在側邊欄提供下拉選單讓使用者切換【縣市】，右側主畫面即時顯示該縣市的用電走勢圖與關鍵指標卡片，完成後請在終端機啟動它。」*

AI 就會自動寫出 `app.py` 並執行 `uv run streamlit run app.py`，你的瀏覽器會自動彈出一個具備現代感、可供任何人互動操作的專業資料 Web 儀表板！

```markdown
## 1. 執行環境與工具規範

## 2. 繁體中文與視覺化字型規範（自動套用，無需使用者提醒）
- 所有的說明回覆、圖表標題、座標軸標籤、圖例與註解，一律使用**繁體中文**。
- 凡涉及 Matplotlib 或 Seaborn 繪圖，一律在 Notebook 第一張圖之前自動加入以下思源黑體字型設定，徹底解決中文方塊缺字與負號亂碼：
  \`\`\`python
  import glob, os
  import mplfonts
  from matplotlib import font_manager
  from mplfonts import use_font

  for f in glob.glob(os.path.join(os.path.dirname(mplfonts.__file__), "fonts", "*.[ot]tf")):
      font_manager.fontManager.addfont(f)   # 註冊 mplfonts 內建字型
  use_font("Noto Sans CJK SC")              # 套用思源黑體，自動處理負號
  \`\`\`
- 使用 Seaborn 繪圖時，搭配 `sns.set_theme(font="Noto Sans CJK SC")`，避免主題重設字型。
- 繪圖完成後，主動檢查負數與中文顯示是否正常。

## 3. 貫徹五步資料分析思維 SOP
在引導每個範例時，必須依照先前思維篇所學之 SOP 推進：
1. **欄位角色貼標籤**：引導學生標記「指標 (Metric)」、「條件 (Dimension)」、「標識 (ID)」，釐清能算什麼、不能算什麼。
2. **套用五大提問積木**：針對問題歸納為「比較、組成、分布、關係、趨勢」。
3. **邊界反向檢核防呆**：劃出分析紅線（缺時間不推趨勢、缺類別不比大小、相關不推因果、ID 絕不加總）。
4. **選對圖表與座標軸**：嚴守座標軸規則（X 軸條件、Y 軸指標從 0 開始、標籤長用水平長條圖、不亂連散佈圖線條）。
5. **分步引導與觀念驗收**：一次只執行一個步驟（A0～A5），每步完成後主動向學生提出一個觀念問題確認理解，確認數據合理後才進行下一步。
```

配置好環境與 `GEMINI.md` 後，進入各案例的操作流程將變得極度流暢：

1. **查看案例情境**：在 GitHub 開啟當次範例的 README（如 `01_class_scores`），了解資料背景與問題。
2. **建立範例資料夾與下載資料**：點選範例 README 的「範例檔下載」連結，儲存至 `01_class_scores/data/`（或直接指示 AI 助教幫你下載）。
3. **A 路線（Notebook 逐步分析）**：在 AI 對話框中發出需求（例如：*「請在 01_class_scores/ 建立 lesson.ipynb，先讀取並觀察 scores.csv」*），AI 將自動遵循規則引導你完成 5 步分析與中文化繪圖。
4. **B 路線（交付專案成果）**：分析驗收無誤後，指示 AI 將邏輯轉為可重複執行的 Python 腳本、Excel 報表或 Streamlit 互動儀表板。


### AI 出錯時的除錯 prompt

```text
這是我執行目前步驟時的錯誤：
（貼上完整錯誤與步驟）
請說明原因，只修正必要部分並重跑。
保留原資料與已完成內容，回報結果與下一步。
```

### 想把成果改成另一種形式時

完成任一例後可以延伸，例如把 Excel 報表改成 Streamlit 應用，或把應用的數據匯出成 Excel。官方資料：[Streamlit 基本概念](https://docs.streamlit.io/get-started/fundamentals/main-concepts)、[openpyxl](https://openpyxl.readthedocs.io/)。

```text
請把我指定範例的成果改成（Streamlit 應用／Excel 報表／HTML 報告）。
沿用原本 Notebook 的資料處理邏輯與清理後資料，不重新產生資料。
保留原本的成果，新成果另存新檔，提供執行命令。
圖表沿用共用字型，全部顯示繁體中文，並依原範例的 B2 驗收。
```
