# AI 協作資料分析｜14 個循序實作範例

> [!TIP]
> **這一章在做什麼？** 你在[看懂資料與選對圖表](../看懂資料與選對圖表/README.md)的 7 堂課學會了「看到資料先想清楚再畫圖」。這一章要把那套想法**真的做出來**：你負責想問題、檢查答案；寫程式交給 AI。
>
> **你不需要會寫程式。** 你需要會的是：說清楚想問什麼、看懂結果對不對。

---

## 一、你和 AI 怎麼分工？

| 你（分析者）負責 | AI（Colab 裡的 Gemini）負責 |
| :--- | :--- |
| 看懂資料：一列代表什麼？哪些欄位能算、哪些不能算？ | 讀取檔案、整理資料 |
| 提出資料**真的能回答**的問題 | 寫程式、計算數字 |
| 決定用什麼圖、為什麼 | 畫出圖表 |
| **檢查答案對不對**：數字能不能回到原始資料核對？ | 依你的回饋修正程式 |

AI 很會寫程式，但它不知道你的資料哪裡有陷阱，也不會主動告訴你「這個結論不能這樣下」。**把關的人是你。**

---

## 二、每一例都用同一套五個步驟

這五步就是前一章學過的思考順序。以 [01 班級成績](./01_class_scores/README.md) 為例：

| 步驟 | 要問自己的問題 | 01 班級成績的例子 |
| :--- | :--- | :--- |
| ① 欄位貼標籤 | 一列代表什麼？哪些是**指標**（可以算）、**條件**（用來分組）、**標識**（只是編號）？ | 一列是一位學生；五科分數是指標；座號是標識，不能拿來算平均 |
| ② 套提問積木 | 我想問的是比較、組成、分布、關係，還是趨勢？資料有需要的欄位嗎？ | 【比較】哪一科全班平均最低？ |
| ③ 邊界檢核 | 有沒有缺值、異常值？分母是什麼？有沒有不能下的結論？ | 缺考是空白，**不能當成 0 分** |
| ④ 選對圖表 | 這個問題該用哪種圖？單位、數值軸起點對嗎？ | 5 科比高低 → 長條圖，數值軸從 0 開始 |
| ⑤ 指揮 AI 並驗收 | 把 Prompt 交給 AI，再核對：圖上的數字和表格一樣嗎？ | 長條圖與表格都顯示數學平均約 62.4 分 |

> 💡 選圖口訣：**比大小用長條、看集中用直方或箱形、看時間變化用折線、看兩個數字有沒有關係用散佈圖（點不連線）**。

> 📇 **做範例時把[資料分析速查卡](../看懂資料與選對圖表/圖解/資料分析速查卡.svg)開在旁邊**：五步驟、欄位標籤、五大問題選圖、六大地雷與三階提問法都在同一頁。

## 三、14 個範例的學習路線

每一例**只多學一件新事情**，其他都是前面學過的。不必一次全部做完，照順序往下走就好。

### 🟢 第一段：熟悉流程（01～02）

| 範例 | 你要回答的問題 | 這一例多學的一件事 |
| :---: | :--- | :--- |
| [01 班級段考成績](./01_class_scores/README.md) | 哪一科平均最低？ | 走一次完整五步驟；**缺考不是 0 分** |
| [02 便利商店銷售](./02_store_sales/README.md) | 哪一類商品整週賺最多？ | 表格裡沒有「營收」欄，要自己算出來（單價 × 數量）；**賣最多件 ≠ 賺最多錢** |

### 🔵 第二段：把亂資料整理乾淨（03～06）

| 範例 | 你要回答的問題 | 這一例多學的一件事 |
| :---: | :--- | :--- |
| [03 圖書館借閱](./03_library_files/README.md) | 哪一類書最常被借？ | 資料分在三種檔案裡，要先**讀對檔案**；用代碼對照表查出分類名稱 |
| [04 社區活動問卷](./04_survey_cleaning/README.md) | 滿意度 1～5 分各有幾人？ | 刪除重複問卷、統一「5分／非常滿意」這類寫法，並**記錄改了哪些資料** |
| [05 連鎖書店季報](./05_bookstore_merge/README.md) | 哪家門市營收最高？ | 把三個月的訂單接起來、對應門市和商品；**找出對不上的資料**，別讓營收悄悄變少 |
| [06 縣市用電](./06_power_reshape/README.md) | 臺北市 24 個月用電怎麼變化？ | 月份排在 24 個欄位裡無法畫趨勢，要先**把表格轉個方向** |

### 🟡 第三段：數對東西、算對指標（07～11）

| 範例 | 你要回答的問題 | 這一例多學的一件事 |
| :---: | :--- | :--- |
| [07 健身房會員](./07_gym_groupby/README.md) | 哪家分店入場最多？ | 同一人會來很多次：**「人次」和「人數」是兩回事** |
| [08 外送訂單](./08_delivery_time/README.md) | 一天中幾點訂單最多？ | 系統時間是國際標準時間，**比台灣慢 8 小時**，要先換算 |
| [09 六城市氣象](./09_weather_charts/README.md) | 臺北一年的氣溫怎麼變化？ | 同一份資料，**問題不同就換不同的圖**；單位不同的數字不放在同一個軸 |
| [10 台北租屋](./10_rent_seaborn/README.md) | 每坪租金大多落在哪裡？ | 找出「月租 1 元」這種**打錯的資料**；用「每坪租金」才能公平比較大小不同的房子 |
| [11 業務週報](./11_sales_kpi_style/README.md) | 哪一組業績達成率最高？ | 比率要先說清楚**分子和分母**；報表加上千分位和百分比 |

### 🔴 第四段：自己來（12～14）

| 範例 | 你要回答的問題 | 這一例多學的一件事 |
| :---: | :--- | :--- |
| [12 共享單車（總整專題）](./12_bike_capstone/README.md) | 一天中幾點借車最多？最後換你出題 | 綜合前面所有技巧；**同一筆有問題的資料，有的問題要排除、有的問題可以保留** |
| [13 辦公室資料](./13_office_chart_basics/README.md) | 各部門一年花多少錢？ | 回到前一章的辦公室資料，**比較、組成、分布、關係、趨勢**五種問題各做一張圖 |
| [14 法務部公開統計](./14_moj_public_data/README.md) | 由你選的官方資料決定 | 使用**真實的政府開放資料**：自己記錄來源、把民國年換成西元、注意最新年度還沒結束 |

## 四、每一例怎麼上？

每一例分成三層，**做完一層再往下**：

| 層次 | 單元 | 做什麼 | 什麼時候做 |
| :--- | :--- | :--- | :--- |
| ✅ 必做主線 | 單元一～三 | 看懂資料 → 檢查陷阱 → 用**一張圖**回答一個問題 | 每個人都要完成，做完**先停下來驗收** |
| 📄 報表應用 | 單元四（01 為單元四～五） | 把結果匯出成 Excel，重新打開核對數字 | 主線驗收通過後 |
| 🚀 選做挑戰 | 單元五以後（01 為單元六～七） | 換另一種問題、再畫一張圖 | 有時間、有興趣再做 |

### 操作步驟

1. 打開範例的 `README.md`，點上方的 **Open in Colab** 按鈕。
2. 在 Colab 執行**第 0 步**儲存格（點左邊的 ▶），它會下載資料並設定中文字型。
3. 每個單元都有一段 **Prompt**：複製後貼到 Colab 右側的 Gemini 對話框。
4. 把 AI 的程式和筆記本裡的**參考程式**對照，執行後檢查結果。
5. 到了「✅ 必做主線驗收」，逐項核對；有不一致就請 AI 解釋並修正。

> 💡 時間不夠時，可以直接執行筆記本裡的參考程式，把時間留給「看懂結果、說出結論」。

## 五、每個範例資料夾裡有什麼？

| 檔案 | 用途 |
| :--- | :--- |
| `README.md` | 這一例的說明書：開頭有「本例速覽」，接著是欄位角色、要問的問題、要注意的陷阱、選圖理由；每個單元的 Prompt 點開即可複製 |
| `lesson.ipynb` | 在 Colab 操作的筆記本；**每個單元都有可直接執行的參考程式**；主線驗收先自己作答，再展開參考答案核對 |
| `images/main_chart.png` | 主線完成後應該畫出的圖，README 開頭就看得到，先知道目標再動手 |
| `data/` | 原始資料和**資料卡**（說明每個欄位的意思和資料裡刻意安排的陷阱） |
| `make_report.py` | 選做：示範把做好的分析交給電腦上的 AI 工具，變成「資料更新後一鍵重跑」的程式 |

## 六、做完一例，檢查自己能不能說出這四句話

1. **一列代表什麼？**（例如：一列是一筆訂單，不是一位客人）
2. **我的分母是什麼？**（例如：每人平均是除以人數，不是除以筆數）
3. **為什麼選這種圖？**（例如：5 個類別比高低，所以用長條圖）
4. **這份資料不能推論什麼？**（例如：兩件事同時發生，不代表一件造成另一件）

能說出這四句，就代表你真的看懂了，而不只是讓 AI 畫出一張圖。

## ⚠️ 使用提醒

- 01～13 是教學用的**模擬資料**，不代表真實世界的店家、學校或人物。
- **不要請 AI 修改原始資料**，讓結果「比較好看」；清理後的資料一律另存新檔。
- Colab 下載資料失敗時，可以從該範例的 `data/` 資料夾手動上傳。
- 14 使用官方開放資料，內容會隨時間更新，你看到的數字可能和教材撰寫時不同；欄位改變時，請用 Prompt 請 AI 依實際欄位重新產生程式。
