# AI 協作資料分析｜循序實作範例庫

本系列承接[看懂資料與選對圖表](../看懂資料與選對圖表/README.md)。學生已學過：**指標／條件／標識的欄位角色**，**比較／組成／分布／關係／趨勢五種提問積木**，以及**缺欄位、缺值、分母、相關不等於因果**等邊界。學生不用手寫 Python，負責提出可回答的問題與驗收；AI 負責產生、執行並修正程式。

每例完全沿用 [01 班級成績](./01_class_scores/README.md) 的五步順序：

1. 欄位角色貼標籤：先說清一列代表什麼，ID 不運算。
2. 套提問積木：只選現有欄位能回答的問題。
3. 邊界反向檢核：缺值、異常、關聯、分母與期間先確認。
4. 選對圖表：比較看長條、連續分布看直方／箱形、時間趨勢看折線、兩數值關係看不連線散佈；標明單位與資料範圍。
5. 用 Prompt 指揮 AI，對照 Notebook 參考程式與原始資料驗收；主線通過後才做報表與選做挑戰。

## 每個資料夾都有什麼

- **`README.md`**：資料專案設定（欄位角色、提問積木、邊界、選圖理由）、逐單元 Prompt、主線驗收清單，以及選做的腳本封裝 Prompt。
- **`lesson.ipynb`**：與 README 同順序的 Colab 筆記本。第 0 步下載資料並設定中文字型；**每個單元（含選做挑戰）都附可執行的參考程式**，主線驗收處列出應核對的實際數字。
- **`make_report.py`**：選做的參考成品，示範把已驗證的流程交給本機 AI 封裝成可重跑的腳本（`uv run python make_report.py`）。
- **`data/`**：原始資料與資料卡（13 使用前導章節的學生素材；14 由學生從官方網址下載）。

## 怎麼使用

**先完成單元一～三並停下來驗收**，再做單元四的報表匯出，最後才是單元五以後的選做挑戰。不是每例都要畫五種圖，也不以圖表數量評分；重點是每張圖都能說出：一列代表什麼、分母是什麼、為什麼選這種圖、資料不能推論什麼。

第一次操作可先複製 Prompt 請 Gemini 生成程式，再與參考程式和實際結果對照；課堂時間有限時，也可以直接執行參考程式，把時間留給解讀與驗收。

資料卡列出各例的教學用資料設計；01～13 的示範資料（13 為前導章節共用素材）不代表真實世界。請勿讓 AI 為符合預期而重造或改寫原始檔。若 Colab 無法下載資料，可從相應資料夾手動上傳到 `data/`。14 為官方公開資料，欄位與數字會隨更新而改變，參考程式會先檢查欄位，不同時請改用 Prompt 讓 AI 依實際欄位產生程式。本機自動化腳本或互動儀表板僅是主線通過後的選做延伸。
