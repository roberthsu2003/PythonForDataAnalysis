## 1️⃣ 本例怎麼學

在 01 的成績表裡，一列就是一個學生，「數列數＝數人數」。到了健身房，一列是**一次入場**，常來的會員會出現上百次。如果老闆問「哪家分店會員最多？」而你數的是列數，答案就錯了。這一例只練一件事：**先確認一列代表什麼，再決定要數「次」還是數「人」。**

| 已經會的（前面範例學過，直接沿用） | 本例新學的（只多這一步） |
| :--- | :--- |
| 一列代表什麼、標識只能計數（01） | 同一個標識（會員編號）重複出現：**count 數人次、nunique 數人數** |
| 分組加總與長條圖（02～05） | 一次分組同時算多種統計（次數、人數、平均、中位數） |
| 直方圖、箱形圖看分布（01 選做） | 多數為 0 的金額：**平均數和中位數差很多**時該看哪一個 |

**學習路線**（做完一層再往下）：

1. **必做主線（單元一～三）**：分清楚入場人次與會員人數，最後用**一張垂直長條圖**回答「哪家分店入場人次最多？」並附上會員人數。單元三後先停下來驗收。
2. **報表應用（單元四）**：匯出分店摘要：入場人次、會員人數、平均每人入場次數。
3. **選做挑戰（單元五～六）**：觀察消費金額為什麼平均數和中位數差很多，或比較各年齡層的運動時間。

## 2️⃣ 資料專案設定：五步 SOP 的前四步

資料：`data/gym_visits.csv`（請先閱讀[本例資料卡](./data/DATA_CARD.md)）。**一列代表：一位會員的一次入場紀錄**，期間 2025-01-01～06-30，共 3,000 列。

### ① 欄位貼標籤
| 欄位名稱 | 資料類型 | 欄位角色 (Data Role) | 說明與規則 |
| :--- | :--- | :--- | :--- |
| **紀錄編號** | 文字代碼 | ⚪ **標識 (Identifier)** | 每次入場的流水號；數它得到「入場人次」。 |
| **會員編號** | 文字代碼 | ⚪ **標識 (Identifier)** | 會重複出現；**數不重複的會員編號才是「人數」**。 |
| **分店** | 文字（4 家） | 🔵 **條件 (Dimension)／類別** | 每位會員固定在一家分店。 |
| **方案** | 文字（4 種） | 🔵 **條件 (Dimension)／類別** | 月繳、季繳、年繳、單次；單次的消費含 250 元入場費。 |
| **年齡層** | 文字（5 組，有順序） | 🔵 **條件 (Dimension)／類別** | 18-24 … 55+；畫圖時要依年齡順序排列。 |
| **日期** | 文字日期 | 🔵 **條件 (Dimension)／時間** | 2025 上半年。 |
| **運動分鐘** | 整數（分鐘） | 🟢 **指標 (Metric)** | 單次入場的運動時間，15～180 分鐘。 |
| **消費金額** | 整數（元） | 🟢 **指標 (Metric)** | 入場以外的加購；**多數是 0**。 |

### ② 套提問積木
- 🎯 **比較（必做）**：哪一家分店的入場人次最多？會員人數的排名一樣嗎？
- 📊 **分布（選做）**：消費金額大多是多少？為什麼平均數和中位數差這麼多？
- 👥 **比較＋分布（選做）**：不同年齡層，每次運動的時間分布有什麼不同？

### ③ 邊界檢核（分析紅線）
- ⚠️ **人次 ≠ 人數**：3,000 列是 3,000 次入場，不是 3,000 位會員；「會員人數」要用 `nunique`。
- ⚠️ **沒出現的會員數不到**：會員編號到 G200，但只有 195 位半年內有入場；這份資料無法得知那 5 位的分店，不能把「有入場的會員數」說成「全部會員數」。
- ⚠️ **方案不能直接比消費**：單次方案的消費金額含 250 元入場費，和其他方案的「加購」意義不同。
- ⚠️ **年齡層差異不推因果**：年長者平均運動時間較短，不能說「年齡造成運動時間變短」；常來的人在資料中出現較多次，也會影響平均。

### ④ 選對圖表
- **4 家分店比入場人次** ➔ **垂直長條圖**（Y 軸從 0 開始；柱子上同時標出會員人數）。
- **消費金額集中在哪裡（選做）** ➔ **直方圖**，加上平均線與中位數線。
- **各年齡層運動分鐘（選做）** ➔ **箱形圖**（多組比較分布，X 軸依年齡順序）。
