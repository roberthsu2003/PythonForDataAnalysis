## 資料與問題設定

本教材原創偽資料，45 位學生、5 科成績；固定 seed=101，假名、非真實學生。

- **分析問題**：哪一科最難？誰需要補救？各科成績是否彼此相關？
- **使用欄位**：座號、姓名、國文、英文、數學、自然、社會；空白代表缺考，不等於 0 分。
- **本例重點**：先把 5 科分數轉成 NumPy 陣列，用陣列運算算出結果，再交給 pandas 整理成表格。
