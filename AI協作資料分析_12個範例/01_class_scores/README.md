## 🧭 資料專案設定：落實思維 SOP

### 1. 欄位角色貼標籤
| 欄位名稱 | 資料類型 | 欄位角色 (Data Role) | 說明與規則 |
| :--- | :--- | :--- | :--- |
| **座號** | 數字流水號 | ⚪ **標識 (Identifier)** | 僅代表學生身份，**只能計數，絕對不能拿來計算加總或平均**！ |
| **姓名** | 文字 | ⚪ **標識 (Identifier)** | 學生姓名，不可參與任何數值運算。 |
| **國文** | 連續數值 (0~100) | 🟢 **指標 (Metric)** | 衡量的成果數值，衡量國文表現。 |
| **英文** | 連續數值 (0~100) | 🟢 **指標 (Metric)** | 衡量的成果數值，衡量英文表現。 |
| **數學** | 連續數值 (0~100) | 🟢 **指標 (Metric)** | 衡量的成果數值，含缺考空值。 |
| **自然** | 連續數值 (0~100) | 🟢 **指標 (Metric)** | 衡量的成果數值，衡量自然表現。 |
| **社會** | 連續數值 (0~100) | 🟢 **指標 (Metric)** | 衡量的成果數值，衡量社會表現。 |

### 2. 五大提問積木與核心問題
- 🎯 **比較（必做）**：哪一科全班平均最高？哪一科平均最低？
- 📊 **分布（選做）**：平均最低的科目，成績主要集中在哪個分數區間？是否存在極端低分？
- 🔗 **關係（選做）**：數學成績與自然成績是否有正向關聯？關聯有多強？

### 3. 邊界反向檢核防呆（分析紅線）
- ⚠️ **缺考（空白/NaN）不可當成 0 分！** 算科目平均時忽略缺考；個人總分只採計已考科目，五科未考齊者暫不參與總分排名。
- ⚠️ **標識欄位不運算**：座號與姓名不可參與任何統計運算。
- ⚠️ **相關不推因果**：就算數學與自然高度相關，也不能推論為「數學好造成自然好」。

### 4. 決定最適圖表
- **科目比平均高低** ➔ **垂直長條圖**（少數類別，Y 軸數值起點必須從 0 開始）。
- **單科分數集中度與極端值（選做）** ➔ **直方圖**（連續數值看頻率區間）與 **箱形圖**（快速抓出離群異常值）。
- **雙科成績連動關聯（選做）** ➔ **散佈圖**（成對數值，點切勿連線）。

## 📋 各單元任務與 Prompt 對照表

### 單元一｜讀取資料與欄位角色檢核（貼標籤）
- **思維重點**：確認「標識 ID」與「指標 Metric」，並統計缺考空值。
- **Prompt 提示詞**：
  ```text
  請幫我用 pandas 讀取 data/scores.csv：
  1. 顯示前 5 筆資料與所有欄位名稱。
  2. 檢查各欄位的資料型態。
  3. 統計每個科目分別有多少人「缺考」（缺失值 NaN）。
  4. 用文字回報：座號與姓名是否為識別標籤，五科成績是否為數值指標。
  ```

### 單元二｜資料防呆與描述統計（必做）
- **思維重點**：缺考不可當 0 分！忽略空值計算各科統計。
- **Prompt 提示詞**：
  ```text
  請計算全班 5 科（國文、英文、數學、自然、社會）的統計數據：
  1. 先計算每科平均分，四捨五入保留一位小數；有餘裕再看最高分、最低分與標準差。
  2. 計算平均時必須「忽略缺考（NaN）」，不可把缺考補 0 分，並在註解說明這樣做的原因。
  3. 將 5 科的統計數據整理成美觀的表格顯示。
  ```

### 單元三｜提問積木【比較】— 哪一科平均最低？（必做，垂直長條圖）
- **思維重點**：少數類別比高低，使用垂直長條圖，Y 軸數值從 0 開始。
- **Prompt 提示詞**：
  ```text
  請用 matplotlib 或 seaborn 畫出 5 科平均成績的「垂直長條圖」：
  1. X 軸為科目名稱，Y 軸為平均分數。
  2. Y 軸數值起點必須從 0 開始，上限設為 100。
  3. 在柱子上方標註具體平均分數數值（保留一位小數）。
  4. 平均最低的科目柱子用醒目的顏色標示，標題寫「平均最低科目」，避免把平均分直接當成題目難度。
  5. 圖表標題、座標軸與標籤全部使用繁體中文。
  ```

### 單元四｜選做挑戰【分布】— 數學科分數集中在哪裡？（直方圖與箱形圖）
- **思維重點**：連續數值看區間用直方圖，抓離群極端值用箱形圖。
- **Prompt 提示詞**：
  ```text
  針對全班平均最低的「數學」科，請畫出圖表來觀察分數分布：
  1. 建立兩張並排的子圖：左邊畫「直方圖（Histogram）」觀察分數集中區間；右邊畫「箱形圖（Box Plot）」觀察中位數與是否有極端低分的離群值。
  2. 直方圖請將分數區間（bins）設為適當大小，並畫出平均線。
  3. 箱形圖標出五數概括與異常值點。
  4. 全圖使用繁體中文標籤，並用圖上的數字描述集中區間；若無明確證據，不必貼上「常態」或「兩極分化」標籤。
  ```

### 單元五｜選做挑戰【關係】— 數學與自然是否有關聯？（散佈圖）
- **思維重點**：成對數值看連動用散佈圖（勿連線），防呆紅線：相關不等於因果！
- **Prompt 提示詞**：
  ```text
  請分析「數學」與「自然」這兩科的成績是否有連動關聯：
  1. 繪製兩科的「散佈圖（Scatter Plot）」，X 軸為數學成績、Y 軸為自然成績。
  2. 每個點代表一位學生，點與點之間「不要連線」。
  3. 計算兩科的皮爾森相關係數（Pearson correlation），並將數值顯示於圖表標題。
  4. 用文字解讀兩科是否存在正相關，並附註「相關性不等於因果關係」的防呆結論。
  ```

### 單元六｜報表應用【比較】— 計算個人總分與班級排名
- **思維重點**：總分與平均分排序，找出前三名優等生與需輔導名單。
- **Prompt 提示詞**：
  ```text
  請計算全班每位學生的成績表現：
  1. 計算每位學生的已考科目總分、平均分與應考科數；缺考不是 0 分。
  2. 五科都考齊者依總分排名；有缺考者標「暫不排名」，不要與完整成績直接比較。
  3. 列出全班總分前 3 名的優等生名單。
  4. 在五科都考齊的學生中，找出平均低於 60 分或有任一科低於 50 分的關懷名單；缺考學生另列待確認名單。
  ```

### 單元七｜報表應用 — 匯出基本 Excel 成績報表
- **思維重點**：將分析結論落地為標準報表檔。
- **Prompt 提示詞**：
  ```text
  請將計算完成的班級成績結果匯出成 Excel 檔案：
  1. 存為 output/成績報表.xlsx（若 output 目錄不存在請自動建立）。
  2. 工作表包含：座號、姓名、五科分數、應考科數、已考科目總分、平均、班級排名、成績狀態。
  3. 先確認缺考學生顯示「暫不排名」；有餘裕再替低於 60 分的科目成績與平均標色，不要標紅座號或排名。
  4. 提供 Colab 下載該 Excel 檔案的程式碼。
  ```
