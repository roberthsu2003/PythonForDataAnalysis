# 03｜圖書館借閱紀錄：Excel、Big5 CSV 與 JSON 一次搞定

你提出需求、看懂結果並驗收；AI 負責寫程式、執行和除錯。此資料夾只提供資料與提示詞，Notebook 與程式由你指揮 AI 在自己的專案中產生。

- 任務：讀寫多種檔案格式、處理編碼與資料型態。
- 交付成果：整合後的 Excel 與 UTF-8 CSV。
- 學生專案內位置：`03_library_files/`；共用專案根目錄的 `.venv`。
- 本例完成後：能用自己的話說明分析問題、資料處理步驟與一個發現。

## 資料與問題設定

本教材原創偽資料，書目 120 本（Excel 兩個工作表）、借閱 600 筆（Big5 編碼）、會員 80 位（JSON）；固定 seed=303。

- **分析問題**：哪類書最熱門？哪些身分最常借書？目前有多少書沒還、借了多久？
- **使用欄位**：書號、分類號、會員編號連結三份檔案；借書日、還書日計算借閱天數。
- **本例重點**：每種格式用對的讀法；讀進來後先檢查型態與編碼，再合併。

觀念連結：[pandas的檔案存取](../../pandas的檔案存取/README.md)、[數據整理：連接、合併和重塑](../../數據整理_連接_合併_重塑/README.md)

## B｜做成交付成果



## 觀念確認

1. 什麼是編碼？Big5 和 UTF-8 差在哪裡？

3. JSON 和 CSV 適合存什麼樣的資料？
