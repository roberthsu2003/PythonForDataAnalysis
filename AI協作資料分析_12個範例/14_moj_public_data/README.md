## 1️⃣ 本例怎麼學

01～13 都是教學用的合成資料，每個陷阱都寫在資料卡裡。這一例換成法務部在政府資料開放平台發布的**真實彙整統計**：沒有資料卡、欄位可能改版、年份是民國年、最新年度通常不完整，有的資料甚至每次下載只有一天。因此本例**不預寫固定答案**；Notebook 中的參考程式會先檢查欄位是否和撰寫時相同，不同就停下來，請你改用 Prompt 讓 AI 依實際欄位產生程式。

| 已經會的（前面範例學過，直接沿用） | 本例新學的（只多這一步） |
| :--- | :--- |
| 讀取 CSV、Excel、XML 等多種格式（03） | 從官方網址下載，寫下**來源卡**；**民國年＋1911** 轉成西元 |

## 2️⃣ 資料專案設定：五步 SOP 的前四步

本例不提供固定的資料檔。請從下表三份官方資料**只選一份**，在 Notebook 第 0 步把 `CHOICE` 改成對應代號，程式會從官方網址下載。下表是撰寫教材時（2026 年 10 月）實際下載核對的內容；**資料會更新，請以你下載當天的實際欄位為準**。

| 代號 | 官方資料來源 | 撰寫時核對的內容 | 一列代表 | 適合的第一個問題 | 必須注意的界線 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| A | [矯正機關每日收容動態](https://data.gov.tw/dataset/101185) | XML，**只有 1 列**：日期、實際收容、男、女、核定容額、超收率、入監人數、出監人數 | 某一天的全國收容快照 | 【比較】實際收容與核定容額 | 只有單日快照，**不能畫趨勢**；資料日期可能早於下載日期 |
| B | [成年勒戒處所新入所收容人人數](https://data.gov.tw/dataset/39440) | CSV：毒品種類、觀勒次數、性別、民國年、月份、人（111 年 1 月起，每月一批） | 某月、某毒品種類、某觀勒次數、某性別的新入所人數 | 【趨勢】每月新入所人數 | 新入所人數**不等於**盛行率；最新年度不滿 12 個月 |
| C | [決定補償金額](https://data.gov.tw/dataset/15128) | CSV：被害補償金類別、民國年、月份、新臺幣元（111 年 1 月起） | 某月、某補償金類別的決定補償金額 | 【比較】最近一個完整年度各類別金額 | 金額**不是**件數或人數，不能當成傷害程度排名 |

### ① 欄位貼標籤
| 欄位名稱 | 資料類型 | 欄位角色 (Data Role) | 說明與規則 |
| :--- | :--- | :--- | :--- |
| **日期（A）、民國年＋月份（B、C）** | 文字／整數 | 🔵 **條件 (Dimension)／時間** | 民國年要＋1911 轉西元；月份是「01」這種文字。 |
| **毒品種類、觀勒次數、性別（B）** | 文字 | 🔵 **條件 (Dimension)／類別** | 分組用；觀勒次數是「初次／再次」，不是數值。 |
| **被害補償金類別（C）** | 文字 | 🔵 **條件 (Dimension)／類別** | 遺屬、重傷、性侵害補償金。 |
| **人（B）** | 整數（人） | 🟢 **指標 (Metric)** | 新入所**人數**；沒有母體人口，不能算盛行率。 |
| **新臺幣元（C）** | 整數（元） | 🟢 **指標 (Metric)** | 決定補償**金額**，不是件數。 |
| **實際收容、核定容額、入監／出監人數（A）** | 整數（人） | 🟢 **指標 (Metric)** | 單日數字；超收率是文字（例如「5.7%」）。 |

### ② 套提問積木
- 🎯 **必做（依所選資料擇一）**：A【比較】實際收容與核定容額差多少？B【趨勢】每月新入所人數如何變化？C【比較】最近一個完整年度，各類別補償金額多少？
- 🧩 **組成（選做）**：A 男女組成；B 各毒品種類×觀勒次數的占比；C 各補償金類別占比——都只用**完整年度**比較。
- 🚫 **先寫下不能回答的問題**：例如「哪裡的人比較容易吸毒？」「政策實施後案件減少了多少是政策造成的？」

### ③ 邊界檢核（分析紅線）
- ⚠️ **先寫來源卡**：發布機關、資料頁網址、下載日期、資料期間、單位、一列代表什麼；來源不清楚就先停。
- ⚠️ **民國年要轉換、期間要完整**：民國 115 年＝西元 2026 年；最新年度若不滿 12 個月，不能和完整年度比較全年總量。
- ⚠️ **單日快照不能畫趨勢**：A 每次下載只有一天的資料，要看趨勢必須每天自行保存，不能用一筆資料說「越來越多」。
- ⚠️ **人數、件數、金額不能互換**：補償金額高不代表案件多；新入所人數不等於盛行率（沒有人口分母）。
- ⚠️ **彙整統計不推個人、不推政策因果**：不能回推任何個人，也不能把同期變化直接寫成某項政策的成效。
- ⚠️ **下載也可能失敗**：A 的官方網站憑證設定不完整，Python 自動下載會被拒絕；請改用瀏覽器下載後上傳，並在來源卡記下下載日期。
- ⚠️ **欄位會改版**：若實際欄位和教材不同，參考程式會停下來；請改用 Prompt 讓 AI 依實際欄位產生程式，**不得補造欄位或數字**。

### ④ 選對圖表
- A【比較】實際收容 vs 核定容額 ➔ **垂直長條圖**（Y 軸從 0 開始，標出資料日期與超收率）。
- B【趨勢】每月新入所人數 ➔ **折線圖**（X 軸由早到晚的年月）。
- C【比較】完整年度各類別金額 ➔ **垂直長條圖**（Y 軸從 0 開始，單位萬元）。
- 【組成，選做】➔ **百分比堆疊長條圖**（每個完整年度一根，寫明分母）；A 只有兩類可用單根 100% 長條。
- 每張圖都要在圖下方註明：資料來源、下載日期、資料期間與單位。

```text
   - 定義 download(), load_data(), check_columns(), build_result(), export_excel() 等清晰函式；資料來源代號 CHOICE 寫成常數。
   - 每次執行都從官方網址重新下載並記錄下載日期；下載失敗時改用 data/ 中既有的檔案，並清楚提示。
   - 欄位與預期不同就停止並列出差異，不可補造欄位；民國年轉西元，最新年度不滿 12 個月要提示。
   - 匯出 output/公開資料分析.xlsx（核心結果、來源卡兩個工作表）。
   - 檔案路徑以腳本所在位置為基準進行相對定位（避免寫死路徑）。
3. 自動執行與驗收：
   - 建立完畢後，請直接在終端機執行：uv run python make_report.py
   - 在終端機印出來源卡摘要、資料期間、不完整年度提示與核心結果的前幾列。
```
