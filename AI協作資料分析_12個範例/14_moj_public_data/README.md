# 14｜法務部公開統計：從服務量到政策溝通

本例適合法務部資料分析員訓練。使用公開、彙整且去識別的統計資料，練習將圖表用於資源配置與服務改善，而不是評價個人或對群體貼標籤。

> [!IMPORTANT]
> 不嘗試回推個人；分清楚人數、件數與金額；同期變化只代表描述或相關，不能直接推論因果。

## 三個真實業務情境

| 情境 | 官方資料來源 | 可練問題 | 關鍵限制 |
| --- | --- | --- | --- |
| 監所收容壓力 | [矯正機關每日收容動態](https://data.gov.tw/dataset/101185) | 收容量與容額趨勢、入監與出監比較 | 單日異常不等於長期趨勢 |
| 毒品處遇需求 | [成年勒戒處所新入所收容人人數](https://data.gov.tw/dataset/39440) | 每月趨勢、毒品類別與性別組成 | 新入所人數不等於盛行率 |
| 犯罪被害補償 | [決定補償金額](https://data.gov.tw/dataset/15128) | 金額趨勢、補償類別組成 | 金額不是件數、人數或案件傷害排名 |

## A｜資料取得與健檢

先從資料來源頁下載 CSV；若來源提供 XML，先請 AI 轉成可讀表格。將檔案放在 `data/`，再執行 Notebook。

```text
我正在分析法務部公開彙整統計。請讀取 data/ 內的檔案，先列出資料期間、欄位、單位、缺值與重複列。
把每欄判斷為類別、數值、時間或識別碼；特別確認「人數、件數、金額」不能混為同一個指標。
在我確認前，不畫圖、不補造資料、不推論個人或個案。
```

## B｜分析與報告

```text
請根據我下載的資料，提出 5 個主管可能關心的問題，標記為比較、組成、分布、關係或趨勢。
我選題後，每題畫一張最適合的圖。所有結論都要註明資料期間、單位與限制。
最後做一頁摘要：3 個可由資料支持的發現、1 個可討論的資源建議、3 個不能做出的結論。
不得由彙整統計推論個人風險，也不得把政策前後的差異直接說成政策造成。
```
