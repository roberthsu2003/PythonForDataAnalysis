# 13｜辦公室資料五圖練習：從圖表到一頁摘要

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/roberthsu2003/PythonForDataAnalysis/blob/master/AI%E5%8D%94%E4%BD%9C%E8%B3%87%E6%96%99%E5%88%86%E6%9E%90_12%E5%80%8B%E7%AF%84%E4%BE%8B/13_office_chart_basics/lesson.ipynb) [開啟教材 Notebook](./lesson.ipynb)

這是「看懂資料與選對圖表」的延伸實作。學生先完成一個問題與一張圖，核對後逐步擴充成五種圖表，最後選三張整理成主管能讀懂的一頁摘要。

## 本例怎麼學：從一張圖到五圖摘要

1. **必做主線**：先用「部門月報」提出一個比較問題，找出對應欄位，做一張部門支出長條圖。
2. **主線驗收**：能說出一列代表什麼、圖上的數字來自哪個欄位；長條圖數值軸從 0 開始，任選一個部門可回查原表。通過後先停下來。
3. **進階應用**：依序加入組成、分布、關係、趨勢四類問題；每完成一圖，先說明它回答的問題與一項限制。
4. **選做交付**：從五圖選三張做一頁摘要，核對每個結論的數字、百分比的分母與圖表單位。

## 資料

- [辦公室圖表練習資料.xlsx](../../看懂資料與選對圖表/學生素材/辦公室圖表練習資料.xlsx)：部門月報、會議室預約、員工問卷、專案工時。
- [辦公室採購明細.csv](../../看懂資料與選對圖表/學生素材/辦公室採購明細.csv)：120 筆採購明細。
- [資料卡](./data/DATA_CARD.md)：欄位、資料範圍與使用限制。

## 任務

1. 先提出「部門平均支出」比較問題，完成一張長條圖並驗收。
2. 再針對組成、分布、關係、趨勢各提出一個問題，逐張完成採購組成、滿意度分布、預估與實際工時關係、每月支出趨勢圖。
3. 選其中三張圖，製作一頁摘要；每個結論都要可由資料重新計算。
4. 解讀時說明平均數與中位數、百分比的分母，以及相關不等於因果。

## A｜一步一步完成 Notebook

### A0｜讀取與健檢

```text
請在 13_office_chart_basics/lesson.ipynb 中讀取兩份辦公室假資料。
原始檔只讀不改。列出每張表的筆數、欄位、資料型態、資料期間與缺值。
把每個欄位標成類別、數值、時間或識別碼；說明它適合回答什麼問題。
```

### A1｜先完成比較問題與第一張圖

```text
請先用「部門月報」提出一個部門支出比較問題，指定欄位與一列資料的意義。
我確認問題後，只畫一張部門支出長條圖；數值軸從 0 開始，圖上標出單位。
任選一個部門，讓我核對圖上的數字與原表；用一句話說明圖不能回答什麼。
```

### A2｜逐步加上其他四類圖

```text
保留已核對的比較圖，依序提出組成、分布、關係、趨勢各一個辦公室問題。
我每確認一題，你再畫對應的一張圖；每張圖用繁體中文，並在圖下用一句白話說明與一項限制。
比例圖標示分母；趨勢圖按時間排序；散佈圖不下因果結論。每個結論的數字都用程式重新計算。
```

### A3｜選做交付：一頁摘要

```text
從已驗收的五張圖選三張，整理成 output/ 的一頁摘要。
每個結論標出來源資料、數字與單位，並寫出三個資料限制。
重新執行並核對圖表、摘要與原始資料一致。
```

## 完成檢查

必做：第一張比較圖可回查原表。進階：五種問題與圖表正確配對，圖表有標題、單位、期間。選做：摘要同時寫出三個發現與三個資料限制。
