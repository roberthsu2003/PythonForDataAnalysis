# 🧯 常見問題排解：Colab 卡住了怎麼辦？

> 遇到問題先別慌。**九成的狀況都能用「重新執行第 0 步」或「從頭依序執行」解決。**
> 下面依「你看到的狀況」分類，找到符合的那一列，照著做就好。

[🏠 回到範例庫目錄](./README.md) ｜ 📇 [資料分析速查卡](../看懂資料與選對圖表/圖解/資料分析速查卡.svg)

---

## ⚡ 先試這三招（最常見的解法）

| 順序 | 做法 | 在 Colab 怎麼按 |
| :---: | :--- | :--- |
| 1 | **重新執行第 0 步**（下載資料、設定中文字型） | 點第 0 步儲存格左側的 ▶ |
| 2 | **從頭依序執行到目前的單元** | 選單「執行階段（Runtime）」➔「執行之前的儲存格（Run before）」 |
| 3 | **重新啟動後全部重跑** | 選單「執行階段（Runtime）」➔「重新啟動工作階段並執行所有儲存格（Restart session and run all）」 |

> 💡 Colab 的變數和檔案都只存在「這一次連線」裡。閒置太久、斷線或重新啟動後，**變數會消失、`data/` 和 `output/` 資料夾也可能被清空**，所以要從第 0 步重跑。

## 一、資料與環境

| 你看到的狀況 | 原因 | 解法 |
| :--- | :--- | :--- |
| 圖上的中文變成 **□□□ 方框** | 還沒設定中文字型，或重新連線後設定消失 | 重新執行**第 0 步**，再執行畫圖的儲存格 |
| 出現 `findfont: Failed to find font weight bold` | 字型沒有粗體版本，系統自動改用一般粗細 | **可以忽略**，不影響圖表內容 |
| `FileNotFoundError: data/xxx.csv` | 資料還沒下載，或連線重設後被清掉 | 重新執行第 0 步；仍失敗就**手動上傳**（見下方步驟） |
| 第 0 步出現 `HTTPError` 或 `URLError` | 網路暫時不穩，或學校網路擋下載 | 等幾秒再執行一次；仍失敗就手動上傳 |
| `ModuleNotFoundError: No module named 'mplfonts'`（或 seaborn） | 套件還沒安裝 | 重新執行第 0 步；或在新儲存格執行 `%pip install -q mplfonts seaborn` |
| `UnicodeDecodeError` | 檔案不是 UTF-8 編碼（例如 03 的 Big5 檔） | 請 AI 改用 `encoding="cp950"` 讀取 |
| 14 下載官方資料出現 `CERTIFICATE_VERIFY_FAILED` | 官方網站憑證設定不完整，Python 拒絕連線 | 用瀏覽器到資料頁下載，再手動上傳到 `data/` |

### 📤 手動上傳資料的步驟

1. 點 Colab 左側的 **📁 檔案** 圖示。
2. 若沒有 `data` 資料夾：在空白處按右鍵 ➔「新增資料夾」，命名為 `data`。
3. 在 `data` 資料夾上按右鍵 ➔「上傳」，選擇從該範例 GitHub 資料夾 `data/` 下載的檔案。
4. 確認檔名和第 0 步程式裡寫的**完全一樣**（包含大小寫與副檔名）。

## 二、執行順序

| 你看到的狀況 | 原因 | 解法 |
| :--- | :--- | :--- |
| `NameError: name 'df' is not defined` | 跳過了前面的單元，或連線重設後變數消失 | 「執行階段」➔「執行之前的儲存格」 |
| `KeyError: '營收'`（某個欄位不存在） | 新增欄位的單元還沒執行 | 從單元一開始依序執行 |
| 數字和驗收答案**不一樣** | 某格被重複執行（例如合併了兩次、重複刪除），或跳過清理步驟 | 「重新啟動工作階段並執行所有儲存格」，再核對一次 |
| 執行很久都沒結束 | 第 0 步正在安裝套件，或網路很慢 | 等 1～2 分鐘；超過 5 分鐘就按停止，再執行一次 |

## 三、和 Gemini 協作

| 你看到的狀況 | 原因 | 你可以這樣回 Gemini |
| :--- | :--- | :--- |
| Gemini 的程式和參考程式**長得不一樣** | 正常！同一件事有很多寫法 | 不用改。只要**結果數字一致**就通過 |
| 結果數字和參考答案不同 | AI 可能漏了清理或用了不同的規則 | 「你的結果是 X，參考答案是 Y，請逐步說明差異的原因。」 |
| AI 把缺值補成 0 | AI 不知道缺值的意義 | 「缺值代表沒有資料，不能當成 0，請在計算時排除缺值。」 |
| AI 拿編號（ID）算平均 | AI 把編號當成數值 | 「『○○編號』是標識，只能計數，請移除這個計算。」 |
| AI 一次畫了好幾張圖 | 指令範圍太大 | 「一次只回答一個問題：＿＿＿，其他先不要畫。」 |
| AI 寫出「因為…所以…」的結論 | 把相關說成因果 | 「這份資料只能看出關聯，請改寫成不含因果的說法。」 |
| AI 想修改或重新產生原始資料 | 想讓結果「比較好看」 | 「不要修改原始檔，清理後的結果請另存新檔。」 |
| AI 產生的程式出錯 | 欄位名稱打錯、或用了不存在的欄位 | 把**錯誤訊息最後幾行**整段複製給 Gemini：「執行出現這個錯誤，請修正。」 |

> 💡 **問 AI 的萬用句型**：「我在做〈範例名稱〉的〈單元幾〉，執行後出現〈錯誤訊息／不一致的地方〉，請用初學者聽得懂的方式說明原因，並給我修正後的完整程式。」

## 四、圖表與匯出

| 你看到的狀況 | 原因 | 解法 |
| :--- | :--- | :--- |
| 執行了但**沒有出現圖** | 程式沒有 `plt.show()`，或畫圖前就出錯 | 往上捲找錯誤訊息；請 AI 在最後加上 `plt.show()` |
| 長條圖看起來差距很大，但數字差不多 | 數值軸沒有從 0 開始（地雷 1） | 「長條圖的數值軸請從 0 開始。」 |
| 標籤文字重疊、擠在一起 | 類別名稱太長或太多 | 「改用水平長條圖」或「把 X 軸標籤旋轉 45 度」 |
| Excel 下載沒有反應 | 瀏覽器擋下了自動下載 | 到左側 📁 檔案 ➔ `output/` ➔ 在檔案上按右鍵 ➔「下載」 |
| Excel 打開後中文是亂碼 | 匯出 CSV 時沒有用 UTF-8 BOM | 請 AI 改用 `encoding="utf-8-sig"` 匯出 CSV，或直接匯出 `.xlsx` |
| 下載的 Excel 數字變成文字、不能計算 | 匯出前把數字轉成了「1,234」這種文字 | 請 AI 保留數值，只用 Excel 格式設定千分位（參考 11） |

## 還是解決不了？

1. 記下：**範例編號、單元編號、錯誤訊息的最後 3 行**。
2. 截圖整個 Colab 畫面（包含出錯的儲存格）。
3. 帶著這些資訊問老師或同學，會比只說「它壞掉了」快很多。
