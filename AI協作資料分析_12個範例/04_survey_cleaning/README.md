# 04｜社區活動問卷大掃除：把髒資料變成能分析的資料

你提出需求、看懂結果並驗收；AI 負責寫程式、執行和除錯。此資料夾只提供資料與提示詞，Notebook 與程式由你指揮 AI 在自己的專案中產生。

- 任務：資料清理：重複、缺值、格式統一、異常值與多選題拆解。
- 交付成果：可重複執行的清理腳本與清理報告。
- 學生專案內位置：`04_survey_cleaning/`；共用專案根目錄的 `.venv`。
- 本例完成後：能用自己的話說明分析問題、資料處理步驟與一個發現。

## 資料與問題設定

本教材原創偽資料，320 列原始問卷（含重複送出）；固定 seed=404，假名與假電話。

### 範例檔下載

- [下載 survey_raw.csv](https://raw.githubusercontent.com/roberthsu2003/PythonForDataAnalysis/master/AI%E5%8D%94%E4%BD%9C%E8%B3%87%E6%96%99%E5%88%86%E6%9E%90_12%E5%80%8B%E7%AF%84%E4%BE%8B/04_survey_cleaning/data/survey_raw.csv)：儲存到學生專案的 `04_survey_cleaning/data/survey_raw.csv`。
- [線上閱讀偽資料卡與欄位字典](./data/DATA_CARD.md)：直接在 GitHub 閱讀，不必下載。

若連結顯示文字，使用瀏覽器「另存新檔」並保留原副檔名。使用這份固定資料，不請 AI 重新生成；本例不需要其他範例的資料。

- **分析問題**：清理後實際有幾份有效問卷？各活動參加人數與滿意度如何？
- **使用欄位**：全部 8 個欄位都需要檢查；原始檔不修改，清理結果另存。
- **本例重點**：每一個清理決定都要記錄「改了什麼、為什麼、影響幾筆」。

## A｜一步一步建立 Notebook

先把本頁網址貼給 AI，再依序貼以下 prompt。一次只貼一段，確認結果後再繼續；AI 無法讀取網址時，貼上本頁內容。

### A0｜讓 AI 認識任務

```text
請閱讀我提供的教材網址，擔任我的資料分析助教。
沿用我已建立的環境，在 04_survey_cleaning/ 工作。
依本例設定逐步建立 lesson.ipynb，保留已完成內容。
用繁體中文說明，只做目前步驟；每步問我一個觀念問題。
能執行就直接執行；不能執行時明說，不編造數字。
Matplotlib／Seaborn 圖表的顯示文字全部使用繁體中文。
現在先說明分析問題、資料欄位與預期成果，不開始寫程式。
```

繪圖前，先貼[共用繁體中文繪圖 prompt](../README.md#共用-promptmatplotlib-與-seaborn-繁體中文繪圖)。

### A1｜讀取與觀察資料

觀念連結：[資料整理和使用前準備](../../資料整理和使用前準備/README.md)

```text
在同一份 Notebook 讀取本例資料，原始檔只讀不改。
讀取 data/survey_raw.csv，所有欄位先以文字讀入。
逐欄列出不同寫法與出現次數，找出所有不一致與可疑值。
先不要修改，整理成一張「問題清單」表格給我看。
缺檔時依上方下載連結取得，不換資料或重新生成。
```

### A2｜清理與整理

觀念連結：[資料整理和使用前準備](../../資料整理和使用前準備/README.md)

```text
移除完全重複的列，記錄移除筆數。
統一性別、居住區、滿意度的寫法；年齡轉成數字。
電話統一成 09 開頭 10 碼；填答時間統一成日期，缺年份的補 2025。
年齡 999、滿意度 6 這類不可能的值改為缺值，不要直接刪整列。
每一步都在清理紀錄表新增一列：步驟、規則、影響筆數。
每一步顯示處理前後的筆數，說明這樣做的理由。
```

### A3｜分析與計算

觀念連結：[資料整理和使用前準備](../../資料整理和使用前準備/README.md)、[群組資料和群組運算](../../群組資料和群組運算/README.md)

```text
把「參加活動」拆開，統計各活動參加人數。
計算各居住區、各年齡層的平均滿意度與填答數。
比較清理前後的筆數與主要統計，說明清理造成的差異。
所有數字都要實際執行得到；不要為了結果好看改資料。
```

### A4｜視覺化與解讀

觀念連結：[直接使用pandas繪制圖表](../../直接使用pandas繪制圖表/README.md)

```text
套用共用字型設定，圖表標題、座標軸、圖例全部繁體中文。
畫各活動參加人數與各區平均滿意度的圖。
說明哪個清理決定最影響結果，以及還有哪些地方無法確定。
```

### A5｜重新執行與保存

```text
重啟 kernel，從頭執行 lesson.ipynb，確認沒有錯誤、圖表中文正常。
把整理後的資料存到 output/，原始 data/ 不覆蓋。
另存 notes.md：資料來源、處理步驟、主要數字與三個發現。
回報實際執行結果與還不確定的地方。
```

## B｜做成交付成果

完成 A5 後再貼 B1、B2。

### B1｜建立可重複執行的清理腳本與清理報告

```text
把清理步驟整理成 clean_survey.py，原始檔只讀不寫。
輸出 output/survey_clean.csv 與 output/cleaning_report.md。
報告列出每個步驟的規則、影響筆數，以及清理前後統計比較。
重複執行結果要相同；以腳本所在位置定位檔案。
不在腳本或應用中重新產生資料；提供執行命令。
```

### B2｜驗收

```text
連續執行兩次，確認輸出檔內容完全相同。
確認原始 survey_raw.csv 沒有被修改。
抽五列，比對原始值與清理後的值，確認規則正確。
寫一份簡短 RUN.md，說明執行方式、輸出與限制。
回報已測試與待確認項目，再問我下方觀念問題。
```

## 觀念確認

1. 為什麼不可能的值改成缺值，比直接刪整列好？
2. 清理紀錄為什麼重要？
3. 多選題為什麼要拆開才能統計？
