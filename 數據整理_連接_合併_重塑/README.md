## 💡 1. 為什麼需要這個觀念？（生活化比喻）

- **merge 就像「按學號對照兩份名單」**：一份是成績單（只有學號），一份是學生名冊（學號 + 姓名）。用「學號」配對，就能在成績單上補上姓名——這就是 Excel 的 **VLOOKUP**。
- **concat 就像「釘書機」**：把 1 月報表和 2 月報表「上下」釘在一起（加列），或把溫度表和經緯度表「左右」釘在一起（加欄）。
- **stack / unstack 就像「把表格轉 90 度」**：長表（一列一筆紀錄，適合電腦處理）與寬表（一列一個對象、欄位是月份，適合人看）之間互相轉換，等同 Excel 的 **樞紐分析表**。
- **多層索引就像「地址」**：只說「中山路 100 號」不夠，要說「台北市 → 中山區 → 中山路 100 號」。年別 + 縣市別兩層名牌，才能唯一定位一列。

| **核心概念** | **生活化直觀比喻** | **傳統工程師痛苦點** | **AI 時代你的角色** |
| -------- | ----------- | ------------ | ------------- |
| `merge` | 按學號對照兩份名單（VLOOKUP） | 配對欄位型態不同，全部配不到 | 說清楚「用哪欄配對、配不到怎麼辦」 |
| `how='left'/'inner'/'outer'` | 保留誰的名單 | 資料筆數莫名變多或變少 | 指定「以哪張表為主」 |
| `concat` | 釘書機：上下或左右釘 | 欄名不一致產生大量 NaN | 說「上下接（加列）」或「左右接（加欄）」 |
| 多層索引 `set_index` | 多層地址 | 取資料時層級搞混 | 說「以年別、縣市別為索引」 |
| `stack` / `unstack` | 表格轉 90 度 | 索引重複就無法轉換 | 描述「列放什麼、欄放什麼」 |
| `pivot_table` | Excel 樞紐分析表 | 參數 index / columns / values 難記 | 直接說出想要的報表版面 |

### 🔹 核心技巧 1：merge——依共同欄位配對（VLOOKUP）

**商業意義**：交易紀錄通常只有「代碼」（車站代碼、商品編號、客戶 ID），要搭配主檔才看得懂名稱、類別、地區，merge 是報表製作最常用的動作。

```python
import pandas as pd                      # 匯入 pandas

traffic = pd.DataFrame({'乘車日': ['20220101'] * 3 + ['20220102'] * 3,   # 每日各站進出站人數
                        '車站代碼': ['0900', '0910', '9999'] * 2,          # 9999 是主檔裡沒有的代碼
                        '進站人數': [8645, 996, 50, 7012, 1043, 40]})
stations = pd.DataFrame({'車站代碼': ['0900', '0910', '0920'],             # 車站基本資料（主檔）
                         '中文站名': ['基隆', '三坑', '八堵']})

left = pd.merge(traffic, stations, on='車站代碼', how='left')    # 以左表為主：配不到的站名填 NaN
print(left)
inner = pd.merge(traffic, stations, on='車站代碼', how='inner')  # 只保留兩邊都有的代碼
print(len(traffic), '→', len(inner), '筆')                      # 6 → 4 筆：9999 被排除
```

### 🔹 核心技巧 2：concat——上下或左右黏在一起

**商業意義**：每個月一份報表、每個分店一份檔案時，用 concat 把它們「疊」成一張總表；或把來源不同但對象相同的資料「並排」。

```python
import pandas as pd                      # 匯入 pandas

jan = pd.DataFrame({'車站': ['七堵', '三坑'], '進站人數': [149018, 35238]})   # 1 月統計
feb = pd.DataFrame({'車站': ['七堵', '三坑'], '進站人數': [126258, 31190]})   # 2 月統計

stacked = pd.concat([jan, feb], keys=['1月', '2月'])   # axis=0（預設）：上下接，用 keys 標記來源
print(stacked)                           # 外層索引是月份、內層是原本的列號

temp = pd.DataFrame({'攝氏': [15.8, 16.5]}, index=['Taipei', 'Taichung'])         # 溫度表
geo = pd.DataFrame({'緯度': [25.05, 24.15], '經度': [121.53, 120.68]},
                   index=['Taipei', 'Taichung'])                                    # 經緯度表
print(pd.concat([temp, geo], axis=1))    # axis=1：左右接，依城市名牌對齊
```

### 🔹 核心技巧 3：多層索引＋ groupby 加總

**商業意義**：觀光景點資料是「年 × 縣市 × 景點 × 月」的細項，先以「年別、縣市別」兩層分組加總，就能回答「每年每個縣市總共來了多少遊客」。

```python
import pandas as pd                      # 匯入 pandas

tour = pd.DataFrame({'年別':   [2012, 2012, 2012, 2013, 2013],
                     '縣市別': ['南投縣', '南投縣', '嘉義市', '南投縣', '嘉義市'],
                     '觀光遊憩區': ['日月潭', '清境農場', '蘭潭', '日月潭', '蘭潭'],
                     '1月': [900000, 599117, 91527, 700000, 88000],
                     '2月': [1000000, 746048, 95000, 800000, 90000]})

by_city_year = tour.groupby(['年別', '縣市別'])[['1月', '2月']].sum()   # 以兩層名牌分組，再加總每月遊客
print(by_city_year)                      # 索引是（年別, 縣市別）兩層
print(by_city_year.loc[2012])            # 只看 2012 年的各縣市
```

### 🔹 核心技巧 4：stack / unstack / pivot_table——換報表版面

**商業意義**：同一份數據，主管想看「縣市為列、年份為欄」，分析師想看「年份為列、縣市為欄」，不必重新整理資料，轉個方向就好。

```python
import pandas as pd                      # 匯入 pandas

wide = pd.DataFrame({'1月': [1499117, 91527, 1028371], '2月': [1746048, 95000, 1100000]},
                    index=pd.MultiIndex.from_tuples([(2012, '南投縣'), (2012, '嘉義市'), (2013, '南投縣')],
                                                    names=['年別', '縣市別']))   # 寬表：月份在欄位上

long = wide.stack()                      # stack：把月份從欄位搬到列上 → 變成長表（一列一個數字）
long.index.names = ['年別', '縣市別', '月份']   # 幫三層名牌取名
print(long)

print(long.unstack('年別'))              # unstack：把「年別」搬到欄位上 → 縣市 × 月份為列、年份為欄

flat = long.reset_index(name='遊客數')   # 把多層索引攤平成一般欄位
print(flat.pivot_table(index='縣市別', columns='年別', values='遊客數', aggfunc='sum'))  # 樞紐分析表：縣市 × 年份的總遊客數
```
