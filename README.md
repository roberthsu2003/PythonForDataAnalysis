## 🤖 零程式碼・AI 協作專區（思維心法 ➔ 實戰演練）

這是一套**完全不需手寫程式**、全程依靠 AI 協作的完整學習路徑。核心理念是**「先建立思維 SOP，再用案例鍛鍊肌肉記憶」**：先在思維篇建立資料認知與選圖標準，隨後在實戰範例中嚴格依循該流程落地實作。

### 🔄 五步標準作業流程（思維貫穿實戰）

```
1. 欄位角色貼標籤 ➔ 2. 套用提問積木 ➔ 3. 邊界反向檢核 ➔ 4. 決定最適圖表 ➔ 5. 提示詞指揮 AI 與驗收
 (指標/條件/標識)     (五大核心提問)       (畫出不可問紅線)     (坐標軸與決策矩陣)     (uv/Colab/Streamlit)
```
