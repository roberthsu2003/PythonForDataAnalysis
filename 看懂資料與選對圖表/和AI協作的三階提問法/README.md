# 🤖 和 AI 協作的三階提問法：讓 AI 一次畫對，而且不亂下結論

> 📚 **本文是「看懂資料與選對圖表」的第 7 課**。前六課學會了「怎麼想」；這一課把想法變成**給 AI 的指令**，並學會檢查 AI 的答案。

---

## 為什麼不能只說「幫我畫圖」？

AI 很會寫程式，但它**不知道**：

- 你的資料一列代表什麼、哪一欄只是編號；
- 你真正想回答的是哪一個問題；
- 哪些結論這份資料其實不能下。

如果只說「幫我分析這份資料」，AI 常會一次畫十張圖、拿編號算平均、或寫出「因為 A 所以 B」的結論。**解法是把一個大指令拆成三階，每一階都由你檢查後再往下。**

| 階段 | 目的 | 對應前面的課 | 你要檢查 |
| :--- | :--- | :--- | :--- |
| **第一階：看懂資料** | 讓 AI 和你對資料有相同的理解 | 第 1、3 課 | 筆數、欄位角色、缺值 |
| **第二階：一次一張圖** | 只回答一個問題，指定圖表與坐標軸 | 第 2、4、5、6 課 | 圖上的數字和表格一致 |
| **第三階：說出限制** | 請 AI 寫結論，也寫出不能推論的事 | 第 3 課 | 沒有把相關說成因果、有寫分母 |

---

## 第一階：看懂資料（先不要畫圖）

**指令範本**：

```text
請讀取 data/辦公室採購明細.csv：
1. 顯示前 5 筆資料、所有欄位名稱、總筆數，以及每一欄的缺值數。
2. 說明「一列代表什麼」。
3. 把每一欄分成：指標（可計算的數值）、條件（類別或時間）、標識（編號，只能計數）。
4. 依目前的欄位，列出 2 個這份資料「可以回答」的問題，和 1 個「不能回答」的問題。
先不要畫圖，也不要下結論。
```

**你要檢查**：
- [ ] 筆數和你打開檔案看到的一樣嗎？
- [ ] 採購編號被歸為**標識**，而不是指標嗎？
- [ ] 「不能回答」的問題說得出理由嗎（例如：沒有簽核日期，不能問審核效率）？

---

## 第二階：一次只問一個問題、一張圖

把第 4～6 課的判斷寫進指令：**問題 ➔ 類別 ➔ 圖表名稱 ➔ X 軸 ➔ Y 軸 ➔ 格式要求**。

**指令範本**：

```text
我的問題是：「2025 年哪一個採購類別的金額最高？」（比較）
1. 先依「類別」加總「金額（元）」，產出由高到低排序的數字表。
2. 再畫【垂直長條圖 Column Chart】：X 軸放類別、Y 軸放金額（元），Y 軸從 0 開始。
3. 柱子上方標註金額（加千分位），金額最高的類別用醒目顏色。
4. 標題、座標軸使用繁體中文，並註明資料期間與單位。
```

**好指令 vs. 模糊指令**：

| ❌ 模糊 | ✅ 清楚 |
| :--- | :--- |
| 幫我畫這份資料的圖 | 回答「哪一類金額最高」，畫垂直長條圖 |
| 畫個比較圖 | X 軸放類別、Y 軸放金額（元），從 0 開始 |
| 好看一點 | 由高到低排序、最高的用醒目顏色、標註數字 |
| 畫出所有分析 | **一次只畫一張**，我確認後再問下一題 |

**你要檢查**：
- [ ] 圖表類型和你在第 6 課選的一樣嗎？
- [ ] 任挑一根柱子，數字和數字表一樣嗎？
- [ ] 數值軸從 0 開始、有單位嗎？

---

## 第三階：請 AI 說出結論，也說出限制

**指令範本**：

```text
請根據剛才的數字表與圖表，用三句話說明：
1. 結論：這張圖回答了什麼？（引用表格中的實際數字）
2. 資料限制：分母是什麼？資料期間多長？有沒有缺值或被排除的資料？
3. 不能推論的事：這份資料不能證明什麼？（例如不能推論因果、不能代表其他年度）
```

**你要檢查**：
- [ ] 結論裡的數字，真的出現在數字表中嗎？
- [ ] 有沒有出現「因為…所以…」「造成」這類因果字眼？
- [ ] 百分比有沒有寫出分母？

---

## 🧯 AI 出錯時怎麼辦？

| 狀況 | 可以這樣回 AI |
| :--- | :--- |
| 拿編號算了平均 | 「『員工編號』是標識，只能計數，請移除這個計算。」 |
| 長條圖 Y 軸沒從 0 開始 | 「長條圖的數值軸請從 0 開始，避免誇大差距。」 |
| 一次畫了好多張圖 | 「一次只回答一個問題：＿＿＿，其他先不要畫。」 |
| 圖上的數字和表格不同 | 「圖上 A 類是 X，表格是 Y，請檢查並說明原因。」 |
| 寫出因果結論 | 「這份資料只能看出關聯，請改寫成不含因果的說法。」 |
| 中文變成方框 | 「請先設定繁體中文字型，再重新畫圖。」 |
