# 📊 看懂資料與選對圖表：辦公室人員的五種圖表入門

> [!IMPORTANT]
> **這一章給一般辦公室人員。** 不必會寫程式，也不必先懂統計。你只要能開啟 Excel、執行 Notebook，並用圖表回答一個具體問題。

你會練習把常見的辦公室資料（部門月報、問卷、專案工時、採購明細）分成五種問題：**比較、組成、分布、關係、趨勢**。先判斷問題，再選圖表；每一張圖都要說得出「它讓人看見什麼」及「它不能證明什麼」。

## 🧭 拿到一組數據時：先這樣思考

> 📖 **專題深入探討**：我們已將圖表決策的完整思維流程、欄位特徵檢驗與防呆檢核獨立整理成專屬章節。
> 👉 **請點此進入閱讀：[【數據選圖思考規則：從資料特徵到最佳圖表的決策指引】](./數據選圖思考規則/README.md)**

不要從「我會畫哪一種圖」開始，而是依下面四步驟縮小選擇：

1. **說出目的**：你要幫誰回答什麼問題？例如「主管想知道哪個部門的每人平均支出較高」。
2. **看欄位，不急著畫**：有沒有時間欄？是一個數值、兩個數值，還是幾個類別？識別碼只能辨識資料列，不能拿來平均或加總。
3. **選問題類型**：時間先想趨勢；部分與整體先想組成；類別間比高低是比較；一堆單一數字看分散程度是分布；兩個數值一起看是關係。
4. **最後驗收圖表**：標題是否包含對象、指標與期間？單位、分母、排序、Y 軸起點是否正確？圖表是否說得比資料更多？

### 快速決策速查表

| 看到的資料／想問的話 | 先選哪一類 | 再挑圖 | 深入規則 |
| --- | --- | --- | --- |
| 「哪一個部門／方案／品項較高？」 | **比較** | 排序長條圖；若同時比較兩個指標，用分組長條圖或點圖 | [比較選圖規則](./數據選圖思考規則/README.md#1-比較-comparison) |
| 「每個部分合起來是一個總數，各占多少？」 | **組成** | 百分比長條圖；類別很少（≤ 4 個）時才用圓餅圖 | [組成選圖規則](./數據選圖思考規則/README.md#2-組成-composition) |
| 「這一欄數字大多落在哪裡？有沒有極端值？」 | **分布** | 直方圖、箱形圖；離散等級可用次數長條圖 | [分布選圖規則](./數據選圖思考規則/README.md#3-分布-distribution) |
| 「兩個數值是否一起升高／降低？」 | **關係** | 散佈圖；超過兩個數值欄位可輔以相關係數熱力圖 | [關係選圖規則](./數據選圖思考規則/README.md#4-關係-relationship) |
| 「數字隨日期、月份或年份怎麼改變？」 | **趨勢** | 折線圖；只有少數時間點可用長條圖輔助 | [趨勢選圖規則](./數據選圖思考規則/README.md#5-趨勢-trend) |

## 🎨 每一類可以用哪些圖表表現？

| 問題類型 | 常用圖表 | 何時用 | 統計與解讀提醒 |
| --- | --- | --- | --- |
| **比較** | 排序長條圖、分組長條圖、點圖 | 比部門、品項、方案或平均值高低 | 單位與分母要相同；長條圖 Y 軸從 0 開始 |
| **組成** | 百分比長條圖、堆疊長條圖、圓餅圖（少於 5 類） | 看各部分占同一個總額的比例 | 一定要寫清楚分母；類別多時改用排序長條圖 |
| **分布** | 直方圖、箱形圖、次數長條圖 | 看單一數值的集中、分散與極端值 | 平均數要搭配中位數或圖形一起看 |
| **關係** | 散佈圖、趨勢線、相關係數熱力圖 | 看兩個或多個數值是否共同變動 | 相關不等於因果；不要用線連接無順序的點 |
| **趨勢** | 折線圖、面積圖、少量時間點的長條圖 | 看數值隨時間的變化 | 時間必須排序；兩個時間點不足以主張長期趨勢 |

> 💡 **口訣**：比高低用長條、看比例先想分母、看集中用分布、看一起變用散佈、看時間變化用折線。

## 🧠 必懂的四個統計觀念

### 1. 平均數不是「每個人都一樣」

例如通勤時間平均 38 分鐘，不代表每位同仁都通勤 38 分鐘。少數很長的通勤時間可能拉高平均；因此要同時看**中位數**與直方圖。

### 2. 百分比一定要有分母

「軟體服務占 30%」一定要追問：占哪一段時間、哪一批採購、哪個總額的 30%？換了分母，結論可能不同。

### 3. 相關不代表因果

專案預估工時與實際工時通常相關，但不能因此說「填更高的預估工時會造成實際工時增加」。專案難度、變更次數等第三個因素都可能同時影響兩者。

### 4. 一張圖要保留脈絡

每張圖至少要有標題、單位、期間與資料來源。長條圖從 0 開始；趨勢圖的時間要由早到晚；類別多時排序；不要用顏色或 3D 效果製造不存在的差距。

## ✍️ 五個辦公室小練習

### A｜比較：部門支出

從 Excel 的「比較_部門支出」工作表回答：「哪個部門的每人平均支出最高？」

```text
請讀取 五類圖表_練習資料.xlsx 的「比較_部門支出」工作表。
先確認部門數、金額單位與缺值；再將每人平均支出由低到高排序。
畫一張 Y 軸從 0 開始的水平長條圖，標題、座標軸與資料標籤都使用繁體中文。
最後用兩句話解讀：最高的是誰、與第二名相差多少；不要把支出高直接說成效率差。
```

### B｜組成：採購類別

從 Excel 的「組成_採購類別」工作表回答：「各採購類別各占總採購金額多少？」

```text
讀取 五類圖表_練習資料.xlsx 的「組成_採購類別」工作表，確認金額欄是數值，以及類別有幾種。
計算每個類別的總金額與占全體採購金額的百分比，合計必須等於 100%。
類別依金額由大到小畫成百分比長條圖；圖下方清楚寫出分母是「全部採購金額」。
請提醒我：這張圖不能回答哪個部門花得最多。
```

### C｜分布：通勤時間

從 Excel 的「分布_通勤時間」工作表回答：「多數同仁的通勤時間落在哪裡？」

```text
讀取「分布_通勤時間」工作表，檢查通勤時間是否皆為合理的正數。
顯示平均數、中位數、最小值、最大值，再畫直方圖與箱形圖。
用白話解釋平均數和中位數各表示什麼；若兩者不同，說明可能代表分布不對稱，不能直接下因果結論。
```

### D｜關係：專案工時

從 Excel 的「關係_專案工時」工作表回答：「預估工時和實際工時有關係嗎？」

```text
讀取「關係_專案工時」工作表，畫預估工時為 X 軸、實際工時為 Y 軸的散佈圖。
計算皮爾森相關係數，並用白話說明相關係數的方向與強弱。
指出至少兩個不能從這份資料得出的結論，例如不能說預估工時造成實際工時，也不能評價個別同仁的能力。
```

### E｜趨勢：每月支出

從「趨勢_每月支出」工作表回答：「全年支出是在增加、減少，還是沒有明顯方向？」

```text
讀取「趨勢_每月支出」工作表，確認月份是正確的時間型態並按由早到晚排序。
畫折線圖，標示每一月的數值，說明資料期間只有 2025 年。
找出最高與最低月份，計算差額；最後說明這只能描述這一年的資料，不能預測明年。
```

## ✅ 圖表送出前的 30 秒檢查
