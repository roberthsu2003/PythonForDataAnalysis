# 📊 🔍 看懂資料與選對圖表：拿到陌生資料不再慌，再把圖表交給 AI 給你建議

> [!IMPORTANT]
> **本章節學習核心**：
> 1. **核心觀念**：拿到任何資料，先判斷每一欄是「類別、數值、時間，還是識別碼」；再把問題歸成「**比較、組成、分布、關係、趨勢**」五類之一——問題類型決定圖表類型。
> 2. **AI 協作能力**：畫圖**之前**，把資料說明交給 AI，請它建議該問的問題；畫圖**之後**，把圖表圖片交給 AI，請它**解讀、診斷、改良**。最後一定要用 pandas **驗證** AI 說的數字。
> 3. **商業決策產出**：面對一份從沒看過的資料，也能有條理地找出重點，做出不會誤導人的圖表，並說出「這張圖告訴我們什麼」。

## 💡 1. 為什麼需要這個觀念？（生活化比喻）

- **拿到陌生資料就像「走進陌生的超市」**：你不會一進門就亂拿東西，而是先看看貨架分類（**認識每一欄**），再想想今天要煮什麼（**要回答什麼問題**），最後才挑食材（**選圖表**）。
- **圖表就像「交通工具」**：去的地方不同，工具就不同。想「比高低」搭長條圖、想「看占比」搭百分比長條、想「看分布」搭直方圖、想「看兩件事有沒有關係」搭散佈圖、想「看變化」搭折線圖。
- **AI 就像「隨叫隨到的資深顧問」**：你可以把資料說明貼給它，問「這份資料可以回答哪些問題？」；也可以把畫好的圖丟給它，問「這張圖告訴我什麼？有沒有畫錯？」——**但顧問也會看走眼，最後拍板的是你。**

| **核心概念** | **生活化直觀比喻** | **傳統工程師痛苦點** | **AI 時代你的角色** |
| -------- | ----------- | ------------ | ------------- |
| 欄位型態 | 超市的貨架分類 | 把訂單編號拿去加總 | 先跑「資料健檢」，確認每一欄能做什麼 |
| 五類問題 | 決定今天要煮什麼 | 拿到資料就亂畫一通 | 把主管的問題歸類：比較、組成、分布、關係、趨勢 |
| 選對圖表 | 選對交通工具 | 用圓餅圖比較 10 個品項 | 依問題類型選圖，並避開常見錯誤 |
| 資料說明給 AI | 先跟顧問說明狀況 | 不知道該問什麼 | 把欄位說明與前 5 列貼給 AI，請它建議問題 |
| 圖表交給 AI | 請顧問看你的報告 | 自己看不出圖哪裡不好 | 上傳圖片，請 AI 解讀、診斷、改良 |
| 驗證 AI | 顧問也會看走眼 | 直接相信 AI 的數字 | 用 pandas 核對 AI 說的每一個數字 |

### 🔹 核心技巧 1：資料健檢——一行看懂每一欄能做什麼

**商業意義**：避免最常見的錯誤，例如把「訂單編號」加總、把「數字存成文字」的欄位拿去平均。這個小工具可以帶走，遇到任何資料都先跑一次。

```python
import pandas as pd                      # 匯入 pandas

def 認識資料(df):
    rows = []
    for col in df.columns:
        s = df[col]
        name = str(col).lower()
        as_number = pd.to_numeric(s, errors='coerce')                       # 試著把整欄轉成數字
        number_like = as_number.notna().sum() >= 0.9 * max(s.notna().sum(), 1)
        if any(k in name for k in ['編號', '代碼', 'id', 'code']):
            kind = '識別碼：只能數有幾個，不能加總'
        elif pd.api.types.is_numeric_dtype(s):
            kind = '數值：分布、關係、分組比較'
        elif number_like:
            kind = '⚠️ 數字卻存成文字：先轉成數字'
        elif s.nunique() <= 30:
            kind = '類別：比較、組成'
        else:
            kind = '文字／種類很多：先取前幾名'
        rows.append({'欄位': col, '判斷': kind, '缺值%': round(s.isnull().mean() * 100, 1), '不重複數': s.nunique()})
    return pd.DataFrame(rows).set_index('欄位')

df = pd.DataFrame({'訂單編號': ['T01', 'T02', 'T03'], '門市': ['信義', '西門', '信義'],
                   '金額': [120, 85, 230], '風速': ['1.4', '2.7', '3.1']})      # 「風速」數字被存成文字（有引號）
print(認識資料(df))
```

### 🔹 核心技巧 2：產生「給 AI 的資料說明」

**商業意義**：AI 看不到你的檔案，你要先「介紹」資料給它。給的資訊越清楚，AI 的建議就越準。

```python
import pandas as pd                      # 匯入 pandas

df = pd.DataFrame({'門市': ['信義', '西門', '逢甲'], '營收': [7880000, 8800000, 9910000], '日期': ['2024-07-01'] * 3})

text = (f'【資料大小】{df.shape[0]} 列 × {df.shape[1]} 欄\n'
        f'【欄位型態】\n{df.dtypes.to_string()}\n'
        f'【前 5 列】\n{df.head().to_string()}')
print(text)                              # 把印出來的內容整段複製，貼給 AI，再加上你的問題
```

### 🔹 核心技巧 3：依問題類型畫圖，並存成圖檔交給 AI

**商業意義**：同一份資料，問題不同、圖就不同。畫完存成 PNG，就能上傳給 AI 請它解讀與挑錯。

```python
import os
import pandas as pd                      # 匯入 pandas
import matplotlib.pyplot as plt          # 匯入繪圖套件

rev = pd.Series({'Fengjia': 991, 'Ximen': 880, 'Kaohsiung': 810, 'Xinyi': 788, 'Tainan': 696})   # 各店營收（萬元）

os.makedirs('給AI的圖表', exist_ok=True)            # 建立放圖檔的資料夾
fig, axes = plt.subplots(1, 2, figsize=(12, 4))

axes[0].bar(rev.index, rev.values, color='gray')
axes[0].set_ylim(650, 1000)                         # ❌ Y 軸不從 0 開始：差距被誇大
axes[0].set_title('Wrong: y-axis does not start at 0')

rev.sort_values().plot.barh(ax=axes[1], color='#8B5E3C')   # ✅ 比較問題：排序長條圖，從 0 開始
axes[1].set_title('Right: sorted bars from 0')

plt.tight_layout()
plt.savefig('給AI的圖表/營收比較_錯與對.png', dpi=150, bbox_inches='tight')   # 存成圖檔，準備上傳給 AI
plt.show()
```

### 🔹 核心技巧 4：驗證 AI——用 pandas 核對每一個數字

**商業意義**：AI 看圖是「目測」，常常讀錯數字或把兩根長條看反。凡是要寫進報告的數字，都要用程式算一次。

```python
import pandas as pd                      # 匯入 pandas

rev = pd.Series({'逢甲': 991, '西門': 880, '巨蛋': 810, '信義': 788, '成大': 696})   # 各店營收（萬元）

print('營收最高：', rev.idxmax(), rev.max(), '萬元')
print('營收最低：', rev.idxmin(), rev.min(), '萬元')
print('最高比最低多：', f'{(rev.max() / rev.min() - 1) * 100:.0f}%')   # 若 AI 說「差了好幾倍」，就是被截斷的 Y 軸騙了
```

## 🤖 4. 指揮 AI 的專屬指令手冊（Prompt 實戰專區）

**本章最重要的一件事：現在有 AI，你不需要獨自判斷該畫什麼、圖畫得好不好——把資料說明和圖表交給 AI，請它給你建議。** 但你要會問、也要會驗收。

> **📋 AI 指揮範本（畫圖之前：請 AI 建議問題與圖表）**：
>
> 「你現在是我的資深資料分析師。以下是一份 **[資料名稱，例如：空氣品質指標]** 的欄位說明與前 5 列：**[貼上資料說明]**。我是非程式背景的初學者，請你：
> 1. 用白話解釋每個欄位的意思，標出最重要的幾欄。
> 2. 建議 5 個主管可能關心的問題，分別屬於「比較、組成、分布、關係、趨勢」哪一類。
> 3. 每個問題建議一種圖表，說明為什麼，並提醒要避免的畫法。
> 4. 指出這份資料的陷阱（型態錯誤、缺值、樣本只代表某一段時間等），並提供繁體中文說明的 pandas 與 matplotlib 程式碼。」

**📷 畫圖之後：把圖表交給 AI**（對圖表按右鍵 →「複製圖片」，貼到 ChatGPT、Claude 或 Gemini；或下載圖檔後上傳）

| 用途 | 直接對 AI 說 |
| --- | --- |
| 🔎 **解讀** | 「這是 **[資料說明]** 的圖（附圖）。請用白話列出 3 個最重要的發現，說明是從圖中哪裡看出來的，最後給老闆 1 個具體建議。」 |
| 🩺 **診斷** | 「請用資料視覺化的專業標準檢查這張圖：有沒有誤導、難讀、或缺少的元素（標題、單位、排序、Y 軸起點、圖例）？請條列並說明怎麼改。」 |
| 🛠️ **改良** | 「請提供改良後的 matplotlib 程式碼，使用繁體中文標題與座標軸名稱。我的資料欄位是：**[貼上欄位名稱]**。」 |
| 🎯 **選圖** | 「我想讓主管一眼看出 **[想傳達的重點]**，這張圖適合嗎？如果不適合，請推薦更好的圖表並說明理由。」 |
| 🆚 **比較** | 「這兩張圖呈現同一份資料（附圖），哪一張比較好？為什麼？」 |

> ⚠️ **驗收 AI 的三個問題**：
> 1. AI 說的數字，和我用 pandas 算出來的一樣嗎？（AI 看圖常常讀錯）
> 2. AI 有沒有提醒資料的限制？例如空氣品質資料只是「某一個小時」，不能說某縣市「一直」比較差。
> 3. AI 建議的改法，套用後真的比較好讀嗎？——**最後做決定的是你。**

> 🕵️ **真實陷阱案例**：在學生素材的空氣品質資料中，PM2.5 和 AQI 的相關係數只有約 0.36。原因是 AQI 取的是「各污染物分項指標中最差的一項」，有些測站的主要污染物是懸浮微粒（PM10）或二氧化氮。如果 AI 看了散佈圖就斷言「PM2.5 越高，AQI 一定越高」，就是一個需要你打折扣的建議。
