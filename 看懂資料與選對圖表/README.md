## 🧭 先問問題，再選圖

| 你想回答的問題 | 適合的圖 | 一個統計觀念 | 常見誤解 |
| --- | --- | --- | --- |
| **比較**：「哪個部門平均支出最高？」 | 排序長條圖 | 比較前要確認單位相同；長條圖的 Y 軸從 0 開始 | 把不同人數部門的總額直接當成效率高低 |
| **組成**：「各採購類別占多少？」 | 百分比長條圖 | 百分比一定要說清楚分母；各部分合計應為 100% | 類別很多時仍硬畫圓餅圖 |
| **分布**：「多數同仁的滿意度落在哪裡？」 | 直方圖、箱形圖 | 平均數會受極端值影響；搭配中位數看更完整 | 只報一個平均數，就說大家都一樣 |
| **關係**：「預估工時較高，實際工時也較高嗎？」 | 散佈圖 | 相關不等於因果 | 看到兩點一起上升，就說 A 造成 B |
| **趨勢**：「每月支出有變化嗎？」 | 折線圖 | 需要有時間順序與足夠期間 | 用兩個時間點宣稱長期趨勢 |

> 💡 **口訣**：比高低用長條、看比例先想分母、看集中用分布、看一起變用散佈、看時間變化用折線。

## 🧠 必懂的四個統計觀念

### 1. 平均數不是「每個人都一樣」

例如通勤時間平均 38 分鐘，不代表每位同仁都通勤 38 分鐘。少數很長的通勤時間可能拉高平均；因此要同時看**中位數**與直方圖。

### 2. 百分比一定要有分母

「軟體服務占 30%」一定要追問：占哪一段時間、哪一批採購、哪個總額的 30%？換了分母，結論可能不同。

### 3. 相關不代表因果

專案預估工時與實際工時通常相關，但不能因此說「填更高的預估工時會造成實際工時增加」。專案難度、變更次數等第三個因素都可能同時影響兩者。

### 4. 一張圖要保留脈絡

每張圖至少要有標題、單位、期間與資料來源。長條圖從 0 開始；趨勢圖的時間要由早到晚；類別多時排序；不要用顏色或 3D 效果製造不存在的差距。

## ✍️ 五個辦公室小練習

### A｜比較：部門支出

從 Excel 的「部門月報」工作表回答：「2025 年哪個部門的平均實際支出最高？」

```text
請讀取 辦公室圖表練習資料.xlsx 的「部門月報」工作表。
先確認資料期間、部門數、金額單位與缺值；再計算各部門平均實際支出並由低到高排序。
畫一張 Y 軸從 0 開始的水平長條圖，標題、座標軸與資料標籤都使用繁體中文。
最後用兩句話解讀：最高的是誰、與第二名相差多少；不要把支出高直接說成效率差。
```

### B｜組成：採購類別

從 `辦公室採購明細.csv` 回答：「2025 年各採購類別各占總採購金額多少？」

```text
讀取 辦公室採購明細.csv，確認金額欄是數值、日期涵蓋的期間，以及類別有幾種。
計算每個類別的總金額與占全體採購金額的百分比，合計必須等於 100%。
類別依金額由大到小畫成百分比長條圖；圖下方清楚寫出分母是「全部 120 筆採購金額」。
請提醒我：這張圖不能回答哪個部門花得最多。
```

### C｜分布：員工滿意度

從 Excel 的「員工問卷」工作表回答：「多數同仁的整體滿意度落在哪裡？」

```text
讀取「員工問卷」工作表，檢查滿意度的有效範圍是否為 1 到 5。
顯示平均數、中位數、最小值、最大值，再畫直方圖或次數長條圖。
用白話解釋平均數和中位數各表示什麼；若兩者不同，說明可能代表分布不對稱，不能直接下因果結論。
```

### D｜關係：專案工時

從 Excel 的「專案工時」工作表回答：「預估工時和實際工時有關係嗎？」

```text
讀取「專案工時」工作表，畫預估工時為 X 軸、實際工時為 Y 軸的散佈圖。
計算皮爾森相關係數，並用白話說明相關係數的方向與強弱。
指出至少兩個不能從這份資料得出的結論，例如不能說預估工時造成實際工時，也不能評價個別同仁的能力。
```

### E｜趨勢：每月支出

從「部門月報」回答：「全年支出是在增加、減少，還是沒有明顯方向？」

```text
將「部門月報」依月份加總實際支出，確認月份是正確的時間型態並按由早到晚排序。
畫折線圖，標示每一月的數值，說明資料期間只有 2025 年。
找出最高與最低月份，計算差額；最後說明這只能描述這一年的資料，不能預測明年。
```
