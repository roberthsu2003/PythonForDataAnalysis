## 第一章 🔍 數據欄位類型與提問思考：看到數據，如何精準發問？

> 📖 **專題深入探討**：我們已將從欄位發想問題的三步思考法、五大提問積木公式與邊界檢核防呆整理成專門指南。
> 👉 **請點此進入閱讀：[【💡 數據欄位與提問思考規則：看到數據，如何精準發問？】](./數據欄位與提問思考規則/README.md)**  
> 🌐 **專題線上互動網頁**：[【💡 數據提問思考規則・線上實驗室】](https://roberthsu2003.github.io/PythonForDataAnalysis/chart-selection/question-rules.html)

拿到一組數據時，**絕不要直接思考「我要畫長條圖還是折線圖」**。第一步永遠是檢視資料的**欄位角色（Data Roles）**。因為**欄位的類型組合，直接限制了這組資料「能回答什麼問題」與「絕對無法回答什麼問題」**。

### 提問思考三步心法（快速摘要）

1. **給欄位角色貼標籤**：
   - 🟢 **指標 (Metric)**：數值型（如：金額、工時、來客數）➔ **代表「我想衡量的結果」**。
   - 🔵 **條件 (Dimension)**：類別或時間型（如：部門、產品、月份）➔ **代表「在什麼情況/誰身上發生」**。
   - ⚪ **標識 (Identifier)**：純流水號/ID（如：工號、採購單號）➔ **只能算筆數，絕不能算平均或加總！**

2. **挑選欄位，套用提問積木**：
   - **單一指標** ➔ 問現況集中區間與極端值（如：通勤時間大多多久？）。
   - **類別 ＋ 指標** ➔ 問高低排名或總體佔比（如：哪部門花費最高？各類別佔比多少？）。
   - **時間 ＋ 指標** ➔ 問演變走向與季節週期（如：營收是成長還是衰退？）。
   - **指標 ＋ 指標** ➔ 問連動性與相關趨勢（如：預估工時與實際工時有沒有關聯？）。
   - **類別 ＋ 時間 ＋ 指標** ➔ 問跨群體走勢分歧（如：各部門每月支出走勢是否一致？）。

3. **邊界反向檢核（畫出不能問的紅線）**：
   - 檢查缺少的欄位，避免問出不可行的假問題（缺時間不問趨勢、缺類別不比高低、相關不推因果）。

> 💡 完整積木問句範本、實戰演練與防呆紅線清單，請詳閱獨立專題：[數據欄位與提問思考規則](./數據欄位與提問思考規則/README.md)。

## 第三章 📊 常用圖表基礎：中英文名稱、座標軸原理與核心用途

> 📖 **專題深入探討**：我們已將常用圖表的中英文代稱、X/Y 軸配置規範、Python 程式碼對照與三大避雷針整理成專門指南。
> 👉 **請點此進入閱讀：[【📊 常用圖表名稱與坐標軸說明：中英文對照與軸線原理】](./常用圖表名稱與坐標軸說明/README.md)**

在決定挑選哪張圖之前，必須先認識圖表的「基本功」：**中文名稱、英文名稱（寫程式或問 AI 必備）、X/Y 軸代表的意義以及圖表的真正用途**。

### 1. X 軸與 Y 軸的黃金配置法則
- **X 軸（橫軸 / 水平軸）**：通常放【條件 / 維度】（如：部門類別、連續日期時間）。
- **Y 軸（縱軸 / 垂直軸）**：通常放【指標 / 數值】（如：金額、工時、數量），**長條圖數值起點必須從 0 開始**！
- ⚠️ **例外對調**：當類別名稱很長或項目很多時，改用**水平長條圖**（Y 軸放類別，X 軸放數值），閱讀最舒服。

### 2. 本章核心圖表中英文與用途速查

| 中文圖表名稱 | 英文名稱 (AI 關鍵字) | X 軸放什麼？ | Y 軸放什麼？ | 核心用途與口訣 |
| :--- | :--- | :--- | :--- | :--- |
| **垂直長條圖** | Column Chart | 少數類別 ($\le 6$) | 數值 (從0開始) | 比少數類別的高低 |
| **水平長條圖** | Bar Chart (Horizontal) | 數值 (從0開始) | 類別 (長標籤) | 排名比大小首選 |
| **分組長條圖** | Grouped Bar Chart | 主類別 (加圖例) | 數值 | 同類別內比對雙指標 |
| **百分比長條圖** | 100% Stacked Bar | 類別或整體 | 百分比 (0~100%) | 看結構佔比首選（優於圓餅圖） |
| **甜甜圈/圓餅圖** | Donut / Pie Chart | （以角度切片） | （以角度切片） | 極少類別 ($\le 4$) 看主導份額 |
| **直方圖** | Histogram | 連續數值區間 (Bins) | 次數／頻率 (筆數) | 看數字集中哪裡（柱子相連） |
| **箱形圖** | Box Plot | 分類（可選） | 數值 (五數概括) | 秒抓極端異常值（離群值） |

## 第四章 📈 最後一步：決定適合的圖表

一旦確定了問題類別，並熟悉圖表特徵後，最後就是根據手邊資料條件（**項目多寡、名稱長短、時間長度、變數個數**）挑選最適合的圖表，並避開視覺化地雷：

- **比大小・比排名（比較）** ➔ 項目少用垂直長條；項目多或標籤長首選**水平長條**；同時比雙指標用**分組長條**。
- **看整體結構佔比（組成）** ➔ 首選**百分比長條圖**；類別極少（$\le 4$ 個）且差異顯著時才用圓餅圖／甜甜圈圖。
- **看集中趨勢與極端值（分布）** ➔ 連續數值用**直方圖**看分布形狀，用**箱形圖**快速抓出離群極端值。
- **看雙變數是否連動（關係）** ➔ 成對連續數值用**散佈圖**（切勿連線）；多變數相關性用**熱力圖**。
- **看隨時間演變走向（趨勢）** ➔ 連續時間點用**折線圖**（時序由早到晚）；時間點極少（3~4 個季度）用**時間長條圖**。

在後續的實戰案例中，你將全程遵循本章所學的 **五步標準作業流程**：
1. **貼標籤**：拿到資料先區分「指標 (Metric)、條件 (Dimension)、標識 (ID)」。
