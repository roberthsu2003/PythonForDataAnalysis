# 📊 常用圖表名稱與坐標軸說明：中英文對照、X/Y 軸原理與核心用途

> 💡 **核心原則：搞懂圖表 DNA，才能正確表達與指揮 AI。**
> 
> 許多同學在看數據分析教材或向 AI 下指令時，常常遇到這些困惑：
> 1. **名稱對不上**：「長條圖」跟「直方圖」長得很像，到底差在哪？英文又該怎麼跟 AI 說？
> 2. **座標軸放反**：X 軸跟 Y 軸到底誰該放數字、誰該放分類？放反了會怎樣？
> 3. **圖表用錯地方**：明明該看排名，卻畫了圓餅圖；明明沒有時間順序，卻拉了折線圖。
> 
> 本章將本教材會用到的核心圖表一次整理清楚，讓你徹底掌握**中英文名稱、X/Y 軸配置規範與真正用途**！

---

## 🧭 一、X 軸與 Y 軸的黃金配置法則

座標軸是圖表的骨架。搞懂 X 軸與 Y 軸的職責，圖表就不會畫錯：

```
       Y 軸 (縱軸 / 垂直軸)
         ▲
         │   通常放：【指標 / 結果】 (Metric)
         │   • 連續加總或平均的數值（如：金額、工時、銷量、人數）
         │   • ⚠️ 長條圖的 Y 軸數值起點「必須從 0 開始」！
         │
         └─────────────────────────────► X 軸 (橫軸 / 水平軸)
             通常放：【維度 / 條件】 (Dimension)
             • 分組的類別名稱（如：部門、產品、門市）
             • 具有先後順序的時間（如：日期、月份、季度）
```

### 📌 關鍵例外：水平長條圖（Bar Chart）
當分類項目名稱很長（例如：「顧客關係管理暨售後服務部」）或項目很多（超過 7 個）時，如果硬塞在 X 軸，文字會重疊或被迫傾斜 45 度難以閱讀。此時**將 X/Y 軸對調**：
- **Y 軸（縱軸）**：改放【類別名稱】（文字水平由左至右展開，閱讀最舒適）。
- **X 軸（橫軸）**：改放【數值指標】（基準線從左側 0 開始向右延伸）。

## 📚 二、本教材核心圖表深度解析

以下依照問題類型，逐一拆解本章會使用的 10 大核心圖表：

### 1. 比較類 (Comparison) 圖表

#### 📊 垂直長條圖 (Column Chart)
- **英文名稱**：Column Chart（在 Python 中常用 `plt.bar()` 或 `sns.barplot()`）
- **X 軸配置**：類別名稱（如：4~6 個部門、品類）
- **Y 軸配置**：連續數值（金額、數量），**底線必須從 0 開始**
- **核心用途**：比較少數（$\le 6$ 個）類別之間的數值高低
- **新手避雷**：類別之間是有間距的，不要和柱子相連的「直方圖」搞混。

#### 📊 水平長條圖 (Horizontal Bar Chart)
- **英文名稱**：Horizontal Bar Chart（在 Python 中常用 `plt.barh()`）
- **X 軸配置**：連續數值（從 0 開始向右延伸）
- **Y 軸配置**：類別名稱（文字水平排列，適合長標籤）
- **核心用途**：比較多個（$\ge 7$ 個）項目或名稱很長時的**排名差距**
- **排版規範**：**強烈建議依數值大小由大到小排序**，避免雜亂無章。

#### 📊 分組長條圖 (Grouped / Clustered Bar Chart)
- **英文名稱**：Grouped Bar Chart / Clustered Bar
- **X 軸配置**：主要分類類別（如：各部門）
- **Y 軸配置**：連續數值
- **圖例 (Hue)**：次要比較指標（如：今年 vs 去年、預算 vs 實際花費）
- **核心用途**：在同一個類別維度下，同時比對 2 個相關指標的差距。

---

### 2. 組成類 (Composition) 圖表

#### 📊 百分比長條圖 (100% Stacked Bar Chart)
- **英文名稱**：100% Stacked Bar Chart
- **軸線配置**：一軸為類別（或單一全體），另一軸為百分比（固定總和為 100%）
- **核心用途**：**商業報告首選！** 觀察各子項目占全體總額的份額結構
- **優勢**：人類眼睛比較「長度」的精準度遠高於「角度」，比圓餅圖更容易判斷比例差距。

#### 🥧 甜甜圈圖 / 圓餅圖 (Donut / Pie Chart)
- **英文名稱**：Donut Chart / Pie Chart
- **軸線配置**：**無 X/Y 軸**。以圓心角與弧長切片代表各成分份額
- **核心用途**：僅限於**類別極少（$\le 4$ 個）**且想強調某一個主導優勢（如：行動端支付超過 65%）
- **新手禁忌**：絕對不能切成 5 片以上；切忌做成 3D 傾斜視角（會扭曲前後切片面積）。

---

### 3. 分布類 (Distribution) 圖表

#### 📶 直方圖 (Histogram)
- **英文名稱**：Histogram（Python：`plt.hist()` 或 `sns.histplot()`）
- **X 軸配置**：**連續數值切分出來的等寬區間 (Bins)**（如：通勤時間 0~10分、10~20分、20~30分）
- **Y 軸配置**：落入該區間的**次數／筆數／頻率 (Count / Frequency)**
- **核心用途**：觀察大量數據是呈現中間高的常態分布、偏左還是偏右
- **重要特徵**：**柱子與柱子之間是緊密相連的**（代表連續數值區間，不可留空隙）。

#### 📦 箱形圖 / 盒鬚圖 (Box Plot)
- **英文名稱**：Box Plot / Box-and-Whisker Plot（Python：`sns.boxplot()`）
- **軸線配置**：一軸為連續數值（顯示 5 數概括：最小值、Q1、中位數、Q3、最大值），另一軸可放分組類別
- **核心用途**：**抓出極端異常值（離群值 Outliers）**的最佳武器；檢驗平均數是否被極端值欺騙。

---

### 4. 關係類 (Relationship) 圖表

#### 🔘 散佈圖 (Scatter Plot)
- **英文名稱**：Scatter Plot（Python：`plt.scatter()` 或 `sns.scatterplot()`）
- **X 軸配置**：第一個連續數值變數（如：預估工時、廣告費）
- **Y 軸配置**：第二個連續數值變數（如：實際工時、營業額）
- **核心用途**：檢視兩個數值指標是否存在同步增加（正相關）或一增一減（負相關）
- **新手禁忌**：**點與點之間絕對不要用折線連起來**！散佈點沒有時間先後順序。

#### 🌡️ 相關係數熱力圖 (Correlation Heatmap)
- **英文名稱**：Correlation Heatmap（Python：`sns.heatmap(df.corr())`）
- **X/Y 軸配置**：兩軸皆為各個數值變數名稱（矩陣交叉）
- **格子顏色**：相關係數數值 $r$（介於 -1 到 +1 之間，深淺反映關聯強弱）
- **核心用途**：欄位有 3 個以上連續數值時，快速全景掃描哪些變數彼此高度牽動。

---

### 5. 趨勢類 (Trend) 圖表

#### 📈 折線圖 (Line Chart)
- **英文名稱**：Line Chart（Python：`plt.plot()` 或 `sns.lineplot()`）
- **X 軸配置**：**具有嚴格先後順序的時間型態**（日期、月份、季別、年份，由左至右遞增）
- **Y 軸配置**：連續數值指標
- **核心用途**：觀察連續時間序列（$> 5$ 個時間點）的成長走向、轉折期與淡旺季
- **防呆底線**：**非時間類別嚴禁連折線**！折線的斜率代表時間演變速率。

#### 📅 時間長條圖 (Time-series Bar Chart)
- **英文名稱**：Time-series Bar Chart
- **X 軸配置**：極少數的時間單位（如：僅有 3~4 個季度或年份）
- **Y 軸配置**：連續數值
- **核心用途**：時間點極少時，用柱狀長條比用兩三點連成的折線更加穩重踏實。

## 🛑 四、初學者必看的「X/Y 軸三大避雷針」

1. ❌ **不要把「流水號 / ID 碼」當成 X 或 Y 軸**：
   - 員工工號 1~100 放 X 軸拉折線，看起來像心電圖，毫無商業意義。
2. ❌ **長條圖的 Y 軸數值基準線「絕對不能截斷」**：
   - 長條圖是靠「面積長度」傳達大小，若將 Y 軸起點設為 80 而非 0，會使微小差距被視覺欺騙放大成好幾倍。
3. ❌ **不要把非時間類別連成折線**：
   - 「行銷部、研發部、財務部」用折線串起來，會讓讀者誤以為從行銷部演變到財務部有成長趨勢。
