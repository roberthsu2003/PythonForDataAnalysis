# 🗣️ 看完圖，怎麼說出可信的結論

> 📚 **本文是「看懂資料與選對圖表」的第 8 課**。前一課你已經會請 AI 畫圖、寫出初步結論；這一課練習親自核對數字、辨認限制，把圖表變成別人能放心使用的一段話。

---

## 一張圖不等於一個結論

看到最高的長條，只能先說「它在這張圖裡最高」。要說得更完整，還要確認：**比的是什麼、差多少、資料涵蓋誰與哪段時間，以及這張圖不能證明什麼**。

請照以下四句話的順序說明，不必使用統計術語：

| 句子 | 問自己什麼 | 寫法 |
| :--- | :--- | :--- |
| **觀察** | 圖上看到了什麼？ | 「2025 年資訊部的每人平均支出最高。」 |
| **證據** | 數字表能核對嗎？差多少？ | 「資訊部為 145,000 元，行政部為 120,000 元，相差 25,000 元。」 |
| **限制** | 資料涵蓋範圍是什麼？不能推論什麼？ | 「這是教學用的 2025 年資料；支出高低不能直接代表部門效率。」 |
| **下一步** | 如果要做決定，還需查什麼？ | 「若要檢討預算，先確認各部門的工作內容和支出項目。」 |

> **口訣：看到什麼 → 數字在哪 → 哪裡不能說太滿 → 接下來查什麼。**「下一步」可以是補資料或查原因；資料不足時，不必硬給建議。

## 用辦公室資料走一次

打開[五類圖表_練習資料.xlsx](../學生素材/五類圖表_練習資料.xlsx)的「比較_部門支出」工作表，對照第 1 張長條圖。下面節錄其中三個部門的數字；完整工作表有五個部門。這是**教學用的模擬資料**，單位是新臺幣元。

| 部門 | 人數 | 2025 年實際支出 | 每人平均支出 |
| :--- | ---: | ---: | ---: |
| 行政 | 18 | 2,160,000 | 120,000 |
| 業務 | 39 | 5,070,000 | 130,000 |
| 資訊 | 46 | 6,670,000 | 145,000 |

**問題：哪個部門每人平均支出最高？**

可以這樣說：

> 2025 年的模擬資料中，資訊部每人平均支出最高，為 **145,000 元**；行政部為 **120,000 元**，兩者相差 **25,000 元**。這裡比較的是「年度實際支出 ÷ 部門人數」，只涵蓋這五個部門的一年資料。**支出較高不代表效率較差**；若要決定是否調整預算，應先查看各部門的支出項目與工作需求。

### 為什麼這段話可信？

1. **回答同一個問題**：圖比較「每人平均支出」，結論沒有偷換成「全年總支出」。
2. **數字能回到表格**：資訊部 6,670,000 ÷ 46 = 145,000；行政部 2,160,000 ÷ 18 = 120,000。
3. **交代範圍與分母**：只談這份 2025 年模擬資料；「每人」的分母是部門人數。
4. **沒有跳到原因或評價**：表格沒有工作量、採購用途或成效，不能據此評定效率。

## 發布結論前的 30 秒檢查

- [ ] **問題對嗎？** 圖、數字表與文字談的是同一個指標嗎？「人數」和「人次」、「總額」和「平均」有沒有混用？
- [ ] **數字對嗎？** 至少挑一個關鍵數字回原表核對；差額或百分比有沒有算錯？
- [ ] **範圍清楚嗎？** 單位、時間、資料對象、被排除的資料有沒有說明？若使用百分比，分母是什麼？
- [ ] **說得太滿嗎？** 單一年份不能宣稱長期趨勢；看到關聯不能宣稱因果；只觀察部分人不能直接代表所有人。
- [ ] **下一步有依據嗎？** 建議做的事是否由資料支持？如果仍缺關鍵資訊，先寫出要補查什麼。

> 如果圖上的數字和原表不一致，先停下來查計算與資料篩選；**不要靠改寫文字讓錯誤的圖看起來合理**。

## ✋ 練習：把說太滿的結論改寫

仍使用上面的工作表。先不要請 AI 寫答案，自己把這句話改成「觀察、證據、限制、下一步」四句：

> ❌「資訊部花錢最多，證明他們最浪費。明年應該先砍資訊部的預算。」

寫完後對照下面的參考答案：

<details>
<summary>展開參考答案與檢查理由</summary>

> 2025 年這份模擬資料中，資訊部每人平均支出為 **145,000 元**，是五個部門中最高的。它比行政部的 **120,000 元**高 **25,000 元**。這份資料只記錄支出與人數，無法判斷支出是否必要，也不能證明哪個部門浪費。若要評估預算，應先按支出項目檢查各部門的實際需求。

原句沒有說清楚比較的是「總支出」還是「每人平均支出」，又把「支出較高」直接說成「浪費」。即使要比較**總支出**，也應明說指標；沒有需求與成效資料，就不能據此決定刪減預算。

</details>

### 再用 AI 幫你挑錯

你寫完自己的版本後，可以把圖表、數字表與這段指令交給 AI，請它當檢查員：

```text
這是我根據圖表寫的結論：【貼上你的四句話】。
分析問題是：【貼上原本的問題】；數字表是：【貼上圖表對應的數字表】。
請逐項檢查：
1. 每個數字與差額能否從數字表核對？請列出核對過程。
2. 指標、單位、時間範圍與分母有沒有說清楚？
3. 有沒有把相關說成因果，或把支出高低當成效率好壞？
4. 下一步是否需要額外資料？
只指出問題與修改建議，不要替我編造資料或直接重寫結論。
```

AI 的檢查意見也要回原表確認。**最後決定怎麼寫的人是你。**
